## 更新日志

- 新增：接入酷狗与汽水音乐，游客可用，也可扫码登录账号。
- 新增：哔哩哔哩音频可搜索点播，并作为跨平台播放的最后兜底。
- 新增：独立搜索页、歌曲评论、探索页模块编排与本地专辑浏览。
- 新增：提供 Linux 安装包（AppImage、deb），Windows 安装更稳妥。

### 音源与账号

- 新增：酷狗音乐支持游客浏览与点播，酷狗 App 扫码后读取账号歌单和「我喜欢」，并优先尝试账号权益可用的整曲。
- 新增：汽水音乐支持游客搜索、主题歌单与听歌模式，可用抖音扫码连接账号并读取我的歌单。
- 新增：哔哩哔哩可搜索音乐区视频音频，支持 BV 号和完整视频链接直达；可从视频信息识别歌曲并匹配歌词，也可切换为同曲专辑封面。
- 新增：网易云和 QQ 音乐改为应用内扫码登录，QQ 同时支持微信扫码。
- 新增：播放试听片段时显示试听徽标。
- 优化：平台图标统一为官方方形图标，顶栏头像跟随当前内容平台；哔哩哔哩并入音源列表，平台专属设置收进各音源的设置。
- 优化：音源与歌词来源使用统一的拖动排序。
- 修复：网易云客户端受限时恢复网页取链播放，减少重复请求并在触发风控时停止重试；音质探测遇到风控不再缓存缺档结果。

### 浏览与搜索

- 新增：独立搜索页，可按平台与类型浏览结果；搜索框重做，修复历史展开与热搜滚动问题。
- 新增：网易云与 QQ 歌曲可查看热门评论和最新评论；网易云新增歌曲精选与本周常听。
- 新增：网易云、QQ、酷狗可浏览全部推荐歌单，并扩充继续听与热门榜单。
- 新增：可按音源开关和排序探索页栏目，并实时预览。
- 新增：本地音乐支持按专辑封面浏览。

### 歌词

- 新增：汽水音乐作为游客歌词来源，支持上游返回的逐字数据。
- 新增：支持手动输入歌名和歌手搜索歌词。
- 修复：恢复歌词弹窗中选中文字的复制快捷键。

### 安装与平台

- 新增：Linux 提供 AppImage 与 deb，关闭窗口、系统字体和更新检测按 Linux 适配；修复窗口按钮压住顶栏控件。
- 优化：Windows 使用标准安装与卸载向导，可自选安装位置，目录固定为 `Simple Music`，不带版本号。
- 优化：Windows 升级会先校验新文件再替换，失败时恢复旧版本；只替换本应用的文件，卸载保留额外文件。
- 修复：静默安装的 `/D=` 支持正斜杠路径。

## 兼容说明

- 无破坏性变更，设置、歌单、播放队列与断点续播数据沿用。
- 酷狗、汽水和哔哩哔哩默认关闭，可在「设置 → 音源与账户」中启用；可用歌曲和音质受平台版权与账号权限限制，部分歌曲只能试听 60 秒。
- 汽水、哔哩哔哩暂无播放缓存、下载和伴奏；酷狗暂不支持生成伴奏。
- Windows 从旧版升级时，如果原目录没有安装归属记录，新版会装到原目录下的 `Simple Music` 子目录，名称冲突时加序号；旧目录中的文件不会自动删除，请从更新后的快捷方式启动。
- Linux 仅提供 x64，更新时需前往下载页获取新安装包。全局快捷键在 Wayland 会话下不生效；桌面歌词不支持点击穿透和跨工作区显示；Wallpaper Engine 需手动选择目录；没有托盘宿主的环境建议把关闭方式设为「退出应用」。
