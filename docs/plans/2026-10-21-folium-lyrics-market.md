# Folium 歌词模组市场第一版

目标版本：2.4.1，功能分支 `feature/folium-lyrics-market`，基于已含内置跃字改进的 `dev/2.4.1`。本次不提交、合并或发布。

## 用户流程

- 现有歌词、跃字、3D 入口和效果保留；歌词页新增「模组」入口，打开同一页面的样式侧栏。
- 默认浏览已验证兼容的歌词动画，可切换查看完整市场或已安装项；截图、名称、作者、安装状态和不可用原因放在一起。
- 安装不改变当前样式。安装后用当前歌曲试用，点击「使用」才保存选择；结束试用回到之前的样式。
- 支持更新和卸载。断网仍可使用已安装项；加载失败回到内置跃字并给出重试入口。

## 兼容边界

- 首版验证原始签名包：虹光 `sample-aurora-visualizer` 1.0.1、52Hz `visualizer52hz` 1.0.1、巨幕 `cinerama` 1.0.0。兼容声明绑定模组 id、版本和已验证内容摘要，市场出现新内容时须再次验证。
- 支持纯 client 的 visualizers 注册、歌词/主题/时钟、旧版时间订阅别名、基础设置及只读频谱。52Hz 的思索教程不进入本应用，使用明确的播放器上下文；不冒充完整 Folium 宿主。
- 首版不运行 main 入口、账户/文件/网络/播放控制扩展，不兼容 Folia 内置动画的调参模组。完整市场中的这些项目显示原因。

## 运行与持久化

- 官方 `catalog.json` 在主进程定址读取；下载路径仅允许官方市场，禁止重定向，设定时间和体积上限。
- 下载同时校验 ZIP SHA-256、Folium Ed25519 签名、实际文件摘要及兼容版本。ZIP 仅在内存读取，拒绝越界路径、符号链接、重复文件和超限解压；签名原字节保存在用户数据目录，不修改包。
- 模组在只允许脚本的 sandbox iframe 中运行，不提供 same-origin、preload、Node 或宿主 IPC；专用协议只读提供校验后的包资源。文档 CSP 禁止网络、嵌套页面、表单和外部脚本；主窗口阻止子框架外跳。
- 宿主只向对应 iframe 发送歌词、显示配置和时钟。消息校验来源窗口与会话，模组消息只用于显示注册结果、状态和错误，不执行宿主动作。
- 安装/卸载串行，安装文件先写临时文件再原子替换；界面选择与设置保存在 UI 本地偏好中，关闭歌词页或切换样式即移除 iframe，停止时钟与频谱订阅。

## 验收

1. 实际市场目录及三种原始包可安装、切换、试用、取消、持久化、卸载；不安装模组仍使用原有跃字。
2. 拖动进度、暂停、切歌、歌词偏移与深浅主题同步；关闭歌词页不保留 iframe 和动画循环。
3. 签名破坏、ZIP 越界/解压超限、无权限 IPC、外部地址和过期响应受测；加载失败可恢复内置样式。
4. 类型检查、相关单测和全量测试；隔离 Electron 用户目录的实际深浅主题与窄窗口截图；独立安全/正确性复核。

## 已知限制

适配不等于支持整个 Folium 平台。首版只承诺以上固定内容的三个视觉模组；macOS 实机验收，其他桌面平台明确记录未验收。市场服务不可用时显示重试，已安装功能保持离线可用。
