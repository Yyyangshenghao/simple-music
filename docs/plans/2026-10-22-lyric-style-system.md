# 动态歌词样式系统（参考 Folia）

目标：让歌词页像 Folia 一样有多种活跃、可调参的动态歌词样式。不再依赖模组市场；模组保留为实验入口。

## 背景与结论

- **Folium 市场以宿主扩展为主**：27 个模组里只有 3 个是歌词动画，其余是任务栏歌词、同步收藏、桌面歌词等功能扩展。
- **Folia 的效果来自内置样式系统**：14 种歌词样式、6 种共享背景、每个样式各有调参面板和播放页快捷参数、选择器内实时预览，以及拍点联动。
- **模组帧率偏低有一部分是我们的问题**：宿主每 32ms 才推一次时钟，只在收到时钟时重画的模组被限在约 30fps。
- **许可证**：Folia 是 AGPL-3.0，本项目是 GPL-3.0-only。约定**只参考视觉效果与交互，按本项目代码重写，不复制 Folia 源码**。效果做到神似，不追求逐帧一致。

## 界面

- 歌词页右上角只保留 `歌词 | 动态` 两段，旁边一个显示当前样式名的按钮（如「跃字 ▾」）。
- 点开这个按钮出现**样式选择器**：
  - 样式卡片：选择器打开时才渲染小尺寸实时预览，关闭即卸载。
  - 当前样式的 2–3 个快捷参数，以及「更多设置」入口。
  - 底部「实验」区：社区模组（即现有市场侧栏）。
- 3D 舞台作为「动态」下的一个样式，原 3D 菜单里的文字风格和参数并入它的设置面板。
- 只有在样式选择器打开时才出现大量选项，平时歌词页只露两段切换和一个按钮。

## 架构

`src/components/Lyrics/styles/<id>/`，每个样式一个目录：

- **`entry.ts`**：声明以下字段：
  - `id`、名称、排序；
  - 懒加载的渲染组件；
  - 参数声明（默认值、范围、类型）；
  - 快捷参数键；
  - 是否使用共享背景。
- **注册表**：根据 entry 生成选择器、设置面板和持久化。设置保存在 `simplemusic-lyric-styles`，内容为 `{ style, tunings: { [id]: {...} } }`。
- **迁移**：旧 `lyricsPanelMode: 'pop' | '3d'` 迁成对应样式，3D 原有设置原样保留。
- **共享运行时**：
  - 当前行与逐字进度、下一句预热；
  - 每帧媒体时钟：暂停、隐藏时停帧，拖动和偏移即时定位；
  - 减弱动态；
  - 节拍信号：基于现有频谱做能量起音检测，样式自己读取。
- **约束**：沿用 `motion-presets.ts` 和 `tokens.css`。同屏只跑一个全屏 WebGL 场景；关闭歌词页即卸载。重型样式先画好第一帧再切换。

## 分阶段

每个阶段单独提交并验收：类型检查、测试、Electron 实机截图，以及帧率和 GPU 探针。

1. **框架与菜单**（已完成，见分支 `feature/lyric-style-system`）：
   - 注册表、共享运行时、样式选择器与快捷参数、设置面板。
   - 跃字、3D 舞台迁入；模组收进实验区，修复 30fps。
2. **轻量样式**（DOM/Canvas，已完成）：
   - **流光**：逐词“等待→演唱→唱后”三态；每句按种子固定的散布排版，演唱中的词发光、起涟漪，唱完留余晖并缓慢漂移。
   - **倾诉**：每句按概率排成 1–4 行，在“常规横排”和“大号斜体错落”两种版式间变化，逐行揭示，字符上下交替错位。
   - **云阶**：先把一句切成块、分列排好再动画，形成稳定的阶梯式错落；带引导线，唱后保留一点结构残影。
3. **浮名**（已完成）：把整首歌词排成一篇纸面文章，镜头在文章中推进；当前句逐字“打印”，唱过的文字逐渐淡去。用 Canvas2D 实现。
4. **PV 族**：这 4 种都是重型样式，每种单独一轮，只做神似的简化版，先做最有辨识度的几种镜头：
   - **凝彩**（已完成）：网点和色块构图，主词放大，文字遇色块反色，镜头沿统一流向接力。
   - **绘光**（已完成）：光场、体积光、星空、线稿，窗口中的发光歌词。
   - **商籁**（已完成）：动态字体镜头，带镜头与故障滤镜，按拍点推镜裂光。
   - **镜台**（已完成）：3D 沿路径飞行，歌词立在场景中，按拍点泛起水镜涟漪。用现有 three.js 实现。

每个样式开工前，先收集 Folia 对应样式的参考录屏，作为验收对照。

## 分支

从 `feature/folium-lyrics-market` 拉出 `feature/lyric-style-system`，第一阶段会改造其中的模组入口。

## 风险

- PV 族每种的规模都相当于一个小项目（Folia 中每个约 0.5MB 源码），只做简化版也需要多轮迭代。
- 多个实时预览同时运行会吃 GPU。选择器里只对可见卡片渲染预览，并降低帧率；重型样式的卡片改用首帧静态图。
- 与 Folia 不可能完全一致，按参考录屏验收神似程度。
