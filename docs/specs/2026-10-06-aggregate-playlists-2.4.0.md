# 2.4.0 应用聚合歌单概念记录

> 历史方案：应用歌单双向同步已于 2026-10-18 撤销，当前边界以[歌单职责收敛](2026-10-18-playlist-boundaries.md)为准。原记录保留供追溯。


日期：2026-10-06。2026-10-16 更新：2.4.0 开发中新增手动网易云及 QQ 同步，尚未发布；QQ 写通道实测状态见下文。

## 核心概念

Simple Music 应有自己的聚合歌单。用户可以把不同音乐平台歌单中的歌曲批量加入应用歌单，在应用内统一整理和播放。聚合歌单由应用独立管理，加入和编辑默认不写回来源平台；用户可手动将全部曲目来自同一网易云或 QQ 平台的应用歌单同步到该账号。

播放队列用于当前播放安排，聚合歌单用于长期保存和管理歌曲集合，两者是不同的概念。聚合歌单保存曲目信息与来源，音频下载仍由现有下载功能单独处理。

## 范围约定

- 聚合歌单归属 2.4.0，首版同时支持网易云、QQ、Apple Music 和本地音乐。
- 歌曲、专辑或平台歌单的多选结果，可以批量加入应用自己的聚合歌单；本地音乐支持更多菜单与多选加入。
- 2.3.1 撤掉本轮新增的批量“添加到平台歌单”入口和能力，不提供批量写入网易云、QQ 等第三方平台自建歌单的操作。
- 批量加入播放队列和下载继续保留。
- 用户确认仅调整新增批量写入；原有“漫游保存到平台歌单”等功能不在本次撤销范围。

## 后续实现的验收目标

- 同一应用歌单能够聚合不同来源歌曲，保留来源与原曲目身份，按来源和 ID 去重，并保留加入顺序。
- 聚合歌单持久化，重启后可继续查看和播放。
- 账号退出、平台停用或曲目失效时显示可用状态，不因此删除聚合歌单内容；播放和下载遵守现有来源能力及账号状态。
- 聚合歌单的加入与编辑不自动向音乐平台发起歌单写入；手动同步更新已关联云端歌单的名称、曲目及顺序。

## 首版实现边界

- 「我的库 → 应用歌单」提供新建、重命名、删除、逐曲移出及上移/下移排序；批量操作中的「加入应用歌单」可以选择已有歌单或新建并加入。
- 独立实体 `AppPlaylist` 不具有平台 `source`；曲目保留来源、ID 和平台播放所需元数据。`simplemusic-app-playlists` 存储 `{ version: 1, items }`，按来源 + `String(id)` 去重并保留首次加入顺序。
- 保存和编辑先写入存档，再发布新状态；写入失败保留旧内容。损坏或未知版本存档保留原始数据并停止写入，界面提供重试读取。v1 存档增量保存漫游标识及按平台、账号隔离的网易云/QQ 目标、成功快照，不保存 Cookie 或会话凭证。
- 收藏不要求已有曲目的平台当前可用，也不筛掉 `playable=false`。展开在线集合和补齐占位详情仍检查来源参与状态、账号会话及取消信号，旧结果不能落盘。查不到详情的 ID 保留为待加载歌曲。
- 音频 URL 不进入收藏存档；本地封面只保存存在标记，展示/播放时按索引 ID 与当前端口/token 重建资源地址。本地文件可用性经只读接口核实，文件移走后仍保留收藏。
- 歌单详情保存完整的离线状态查询结果，不受全局徽标缓存上限影响。平台停用/退出时保留原收藏并显示状态；网易/QQ 有确认的离线文件时可播放，Apple 仍要求独立官网会话。
- 播放全部或追加队列使用当前可用歌曲的副本，跳过暂不可用歌曲；编辑或删除收藏不改变已安排的播放队列。下载继续使用既有网易/QQ 能力，Apple 和本地文件不进入普通下载。

## 2026-10-16 手动同步与漫游约定

- 用户确认采用手动单向同步：首次创建网易云私密歌单，之后更新同一份；不做自动同步或云端反向合并。
- 混合来源、Apple 和本地曲目不能同步，不过滤后偷偷写入部分内容。新空歌单不创建云端目标；已关联歌单删空后允许明确点击更新为空。
- 漫游每次生成独立应用歌单，先本地落盘成功才结束生成；保留旧本地漫游一次迁移与旧云端只读恢复入口。
- 创建后的部分失败记录目标，重试复用；网易云成功必须核对完整顺序，账号变化、删除及同步中继续编辑不能被迟到响应覆盖。删除应用歌单不删除云端歌单。

## 2026-10-16 QQ 同步扩展

- 全 QQ 歌单手动同步名称和歌曲集合，首次私密新建，后续更新同一目标；各账号与网易云记录互不串用。仅支持私密普通歌单，名称不超过 20 字符。
- 官网未发现可证实的歌曲排序写接口，顺序以 QQ 端为准，页面明确标注；不通过清空重加伪造排序。
- 旧档未记录类型时，写前查询真实 MID/数字 ID/类型；增删分批、逐级业务码与最终全量读回校验。改名保留云端简介、封面、标签和可见性。
- 本机 QQ 普通私密歌单已通过授权真实账号的创建、名称/歌曲更新、幂等及清理，原有歌单未被写入；红心历史业务码 80105 仍不据此视为可写，见 [验收记录](../reviews/2.4.0-app-playlist-qq-sync.md)。
