# 2.4.0 应用歌单聚合展示与验收

应用歌单是本轮重点功能，负责把网易云、QQ、Apple Music 与本地音乐长期保存在同一集合。它不写回平台，不把本地文件算作在线平台，不把不可播放等同于不可收藏。

## 本轮展示

- 我的库首次进入默认展示应用歌单；平台歌单仍由独立分类管理。
- 总览与详情统一使用真实曲目封面拼图；来源标签与数量明确展示混合组成，平台停用仍能辨认已收藏来源。
- 首次使用提供明确的新建和加入方式；新建成功进入空歌单。加入弹窗展示目标歌单已有来源，降低与平台歌单的混淆。
- 延续现有主题与字体，不新增宣传大卡、自动平台匹配、同步或跨平台替换逻辑。

## 验收目标

- 四种来源可混合创建、持续追加、重启恢复；同来源数字/字符串 ID 去重，不同来源同 ID 不互相覆盖，原始加入顺序保留。
- 保存曲目元数据与播放身份，不持久化音频 URL、本地临时 token；禁用、退出或缺失文件不删除收藏。
- 播放全部与追加只取当前可用曲目，顺序与来源正确；Apple 使用独立会话，网易/QQ 可使用已确认离线音频；整理不改当前队列快照。
- 真实 Electron 检查默认入口、四源混合总览/详情、无平台空态、创建/加入/改名/排序/移除、深浅主题、长名称和 960×540 最小视口。
- 隔离测试配置下实际扫描并播放临时本地音频；云平台界面用明确的模拟数据，不进行真实账号歌单写入，也不以模拟测试声称验证受保护云端播放。
- 类型检查、全量测试与独立复核通过后本地 Squash 合入 dev/2.4.0，不升级或发布。
