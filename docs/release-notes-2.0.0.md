# Simple Music 2.0.0 发行说明

> 2.0 多平台融合版本。

## 主要变化

- 从“切换一个音源”升级为“同时启用多个平台”：网易云与 QQ 均可参与探索、我的库与播放。
- 探索页与我的库共用一个全局内容平台，通过侧边半隐藏 Dock 同步切换；不提供“全部平台”，单平台用户不会看到多余入口。
- 内容与播放来源可辨认，来源标识支持常显、动态和隐藏。
- 设置页以“播放接力”统一配置跟随歌曲来源、固定平台顺序和失败自动换源；顺序支持拖动与键盘调整，并按“同平台候选/降质 → 下一平台”有限降级。
- 设置页升级为宽屏双列控制中心；探索、我的库、榜单与漫游统一响应式内容宽度，窄窗口自动回落而不挤压控件。
- 平台未登录、未启用或登录过期时不参与请求、内容和播放候选。
- 1.x 设置与混合播放队列可迁移，旧设置原文会保留备份。

## 兼容说明

- 升级时只启用 1.x 原来选择的平台；其他已登录平台仍需用户在“音源与账号”中明确启用。
- 播放队列会恢复为暂停态，实际音频地址在用户再次播放时按当前平台状态重新解析。
- 第一次稳定迁移前请勿删除 `simplemusic-settings-v1-backup`。

## 验证情况

- 全量 typecheck + 436 个自动化用例通过。
- 网易云、QQ 双账号内容与播放自动化冒烟通过（打包产物 + playwright 驱动，全程 0 console error）。
- 窄窗口响应式与 Dock 布局自动化验证通过。
- 主观听感、真实输出设备切换、VoiceOver 读屏、代码签名仍待人工验收。
