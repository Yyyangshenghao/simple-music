## 更新日志

- 新增：应用歌单聚合网易云、QQ、Apple Music 与本地歌曲，支持整理及直接管理本人平台歌单。
- 优化：独立后台播放运行时，游戏模式释放主界面，未完成下载可在重启后手动继续。
- 优化：悬浮播放栏、歌词排版、音乐库分类与横排拖动，改善刷歌预加载和页面滚动体验。
- 修复：QQ 红心与最近听过、换号缓存隔离、队列操作、歌词补全、页面往返及卡片和标题阴影。

## 兼容说明

- 首次升级会将播放相关存档迁移至后台分区，逐项读回确认后启用；原界面分区保留旧存档备份，迁移失败不会删除原数据。冷启动恢复为暂停，未完成下载等待手动继续。
- 应用歌单只管理应用内的聚合收藏；网易云、QQ 的本人歌单通过平台入口创建、改名、加入及移出歌曲。旧同步关联停止使用，不自动同步、整体覆盖或删除已有云端歌单；正常保存应用歌单后不再保留旧同步关联。
- 平台写入限当前账号可管理的歌单，同源歌曲增量加入，部分失败按实际结果提示。网易云“我喜欢的音乐”及 QQ 红心继续通过喜欢操作管理；Apple Music 平台歌单保持只读。
- Apple Music 继续使用独立官方受保护播放会话，不参与跨平台音频补位与离线音频缓存。在线歌曲的可播性仍取决于账号权益、地区及平台接口。
- 普通控件改为鼠标操作，不再提供 Tab、Enter 或方向键导航与激活；已配置快捷键、文字输入及快捷键录入保留。
- 沿用现有本地音乐、应用歌单和用户设置，无需手动迁移。回退旧版本不会自动把后台分区的新播放状态覆盖回旧存档。
- WMA（WMAv2）仍存在解码不兼容，不能保证播放；本版未改变这一已知限制。
- Windows 提供安装版与便携版；macOS 提供 Intel 与 Apple Silicon 安装包。

## 验证情况

- 发布前本地类型检查、294 个测试文件共 2,780 项测试、源码构建，以及版本文件和四条发行摘要格式校验通过；完成独立发布范围复核。
- 已有 macOS Electron 阶段验收覆盖独立播放宿主、游戏模式、断点恢复、下载恢复、应用歌单、歌词与横排交互；近期补充检查包含简介与说明展开、预览跨页关闭及深浅主题标题样式。
- 新增平台歌单管理接口的异常与归属边界有自动化及隔离界面覆盖；历史双向同步的实号验收不等同于当前管理接口的完整实号验收。
- Windows 原生窗口、实际安装更新、设备切换、实体媒体键、真实平台音频与 Apple Music DRM 的完整端到端流程仍存在实机验证缺口。未将合成账号、静音样本或隔离预览计作真实平台及全部设备通过。
- 发布流程对 Windows/macOS 执行类型检查、测试和构建；正式标签工作流另执行生产 VMP 签名、打包与必需产物检查，最终结果以该版本工作流为准。
