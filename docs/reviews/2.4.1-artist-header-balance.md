# 歌手简介向中间收回

2026-10-23。上一版把歌手信息按比例放大，简介因此离歌手名太远。现在将左栏限制为最多 560px，简介在相邻列左对齐，最宽仍为 640px；窄窗口上下排列、字号与展开方式保留。

1536px 视口中，简介起点从约 x=850 收回到 x=654。长名字文字列仍有约 392px，比最初仅约 252px 的版本更宽。没有简介时左侧仍可占满内容宽度。
