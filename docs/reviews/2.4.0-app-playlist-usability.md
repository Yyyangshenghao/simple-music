# 2.4.0 应用歌单可用性修正

所属版本：2.4.0；功能分支：`feature/app-playlist-usability`，基于 `dev/2.4.0`。本轮处理五项已确认问题，不修改版本、平台歌单或发布状态。

## 改动

- 批量移出与清理失效歌曲仅在保存成功后提示成功，失败保留选区。
- 歌曲行分别提供播放按钮与整理按钮，不可播放歌曲仍能加入应用歌单；保持虚拟列表 56px 行高。
- 刷歌、播放队列、歌单/专辑预览增加收藏入口；预览整份收藏按完整集合展开，不把预览前缀当作全量。迷你条通过校验窗口和主框架的专用 IPC 返回主窗口选择歌单，并绑定点击时曲目。
- 单曲与批量选择器共用最近目标顺序及记忆，超过五份歌单时显示名称搜索；已知完整曲目时展示重复数量，结果回执包含目标名称和实际新增数量。歌单详情的添加歌曲按钮直接打开搜索并优先该歌单。
- 单曲移出提供六秒撤销，恢复原位置并保留期间新增歌曲；撤销失败可重试，已删除歌单不会重建。撤销回调保存在独立的主界面提示 store，不经播放宿主或 IPC 序列化。

`npm run typecheck` 通过；全量 `npm test` 共 285 文件、2683 项通过。回归覆盖保存失败不假成功、不清选区，撤销的位置、去重、存储失败与删除边界，歌单筛选与真实回执，pending 解析和取消，预览完整集合及迷你 IPC 身份边界。
