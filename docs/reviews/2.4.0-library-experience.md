# 2.4.0 库与探索交互优化

目标：`dev/2.4.0`；工作分支：`feature/library-experience`。本阶段不修改版本号、不推送或发布。

## 交付范围

- 库的在线歌单、专辑和收藏复用现有 5 分钟、有容量上限的平台缓存；歌单与探索共享数据及在途请求。刷新保留卡片，初次加载有稳定占位。
- 库分类使用跟手玻璃滑块及现有弹簧节奏，松手切换；支持取消、方向键和 Home/End，保留用户组合快捷键。
- 探索“你的歌单”在内容溢出时显示胶囊拖动把手和前后翻页，跟手拖动保留精确位置，翻页沿用平滑滚动及减少动态效果偏好。
- 共用页面滚动样式将轨道顶部移至顶栏下方，底部避开播放栏，长列表滑块最小 44px。
- 设置新增“页面布局：保留边框 / 内容延展”。默认沿用边框，延展时放宽内容并去掉探索和库的栏目外框；经真实宿主命令持久化，主界面重连保留选择。

## 验证

真实 macOS Electron 开发窗口，独立 userData；使用 CDP 设置 1280×800 和 900×640 内容视口。测试歌单、封面和 870 首曲目为隔离验证资料；榜单来自公开接口。截图来自实际 React 界面，未重绘。

- 库标签反复切换复用缓存；鼠标拖动、点击、方向键、取消及减少动态效果检查通过。
- 人为制造刷新失败后已有卡片保留；账号退出后迟到结果不显示、不进入当前缓存。
- 870 首列表的轨道顶部 64px、底部留 132px、滑块最小 44px；从顶部拖动后 scrollTop 到达 12746px。
- 探索把手可拖至末端（100%）；布局开关同步到独立宿主，主界面重新加载后仍为延展；900px 下页面无横向溢出。
- 类型检查、全量测试及独立复核通过；复核发现的宿主动作遗漏、Shift 快捷键避让均有回归覆盖并已修复。
- 未在 Windows/Linux 实机验证，也未使用真实 QQ/Apple 账户逐项验收；平台缓存失效沿用原有通路。
