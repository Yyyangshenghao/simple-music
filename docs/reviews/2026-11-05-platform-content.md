# 2.7.0 第一批平台内容实施与验证

2026-11-05，目标分支 `dev/2.7.0`。范围按维护者确认的[第一批四项](../specs/2026-11-05-platform-content-2.7.0.md)实施，其他候选未进入本次开发。

## 已接入口

- 网易、QQ、酷狗的探索页增加「浏览全部歌单」，复用现有推荐供给和预览详情。支持继续加载、重复项目和游标终止、失败重试、账号隔离及返回恢复。
- 网易探索页增加「本周常听」，展示六首预览，播放全部与查看全部使用完整周榜。数据来自平台近一周歌曲列表，未增加播放次数或全时段排行。
- 汽水加入内容平台切换，探索展示本机「继续听」及含汽水曲目的应用歌单。歌曲操作只使用汽水历史，混合应用歌单打开完整集合。平台歌单与收藏页说明游客无账号曲库。
- Apple 探索页增加「歌曲与专辑榜」，榜单页支持歌曲、专辑和歌单三类切换；保留原歌单榜与地区榜。分类分别保留加载结果和滚动，歌曲支持现有歌曲行操作，专辑使用现有预览详情。

## 验证结果

`npm run typecheck && npm test` 通过，417 个测试文件、3976 项通过、2 项跳过。针对性回归覆盖来源选择、分页去重/无进展终止、换号与停用的迟到响应、来源页保留和播放集合范围。独立复核提出的 Apple 无增量分页与汽水库空态已处理，最终复核未发现阻塞问题。

通过 `npm run dev` 启动实际 Electron，并执行只读接口与导航检查。网易、QQ、酷狗推荐首批分别返回 30、20、30 张歌单；网易周榜返回 100 首。网易完整歌单实际继续加载至 90 张，打开预览、进入详情并返回后仍有 90 张，滚动保持 500px。

独立浏览器上下文加载同一开发渲染入口，以构造数据验证深浅主题、1440×960 与 960×720 窗口、分类按钮悬停/按下/松开、专辑预览详情与返回、完整周榜和汽水详情。分页夹具从 24 张增长至 48 张后终止。汽水播放范围为九首汽水歌曲，Apple 歌曲榜翻页后播放范围为 28 首 Apple 歌曲，周榜详情保留全部 28 首夹具歌曲。无页面运行异常或页面级横向溢出。

具体计数见[结构化验证记录](2.7.0-platform-content-verification.json)。界面夹具中的播放动作用队列接收记录核对曲目范围，未实际启动音频。真实 Electron 导航检查未修改平台内容。

## 剩余验收边界

当前实际 Apple 会话未连接账号。歌曲/专辑榜的真实上游读取、地区差异、账号权益及受保护播放需连接账号后验收。本次未重验其他平台真实整曲播放。QQ 和酷狗已验证真实推荐读取，完整页面的交互由共用浏览页与夹具验证，未分别在两个真实账号下完成全部详情往返。
