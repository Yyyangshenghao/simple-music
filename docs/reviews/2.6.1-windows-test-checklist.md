# 2.6.1 Windows 实机测试清单

2.6.1 的打包、覆盖安装与 mac 原地替换已在 macOS arm64 上实测通过（2026-11-01，见下方「mac 已验证」）。本机无法验证 Windows，以下各项需要在 Windows 10/11 x64 实机上逐条走一遍，结果回填到发行说明「验证情况」。

## 准备

- 一台已安装 **2.6.0**（NSIS 安装版）并登录过网易云/QQ 的 Windows 机器；另备一份 2.6.0 便携版（portable）。
- 在 dev/2.6.1 上打包：`npm run build:win`。原地升级需要「比已装版本新」的安装包：正式发布前测试时，可额外打一个假版本号包 `npx electron-builder --win -c.extraMetadata.version=2.6.2`，测完删除，不要上传。
- 用户数据目录：`%APPDATA%\Simple Music`；更新目录：`%APPDATA%\Simple Music\updates\downloads`。

## 1. 安装包本身

- [ ] `dist\Simple-Music-2.6.1-Setup.exe` 体积与 2.5.1（约 145MB 级）相近，明显偏大时先查原因（2.6.0 曾把整个仓库打进 asar）。
- [ ] `npx @electron/asar list "dist\win-unpacked\resources\app.asar"` 只有 `out/`、`node_modules/`、`package.json`、`build/icon.*`。
- [ ] `dist\win-unpacked\resources\app.asar.unpacked\node_modules\onnxruntime-node\bin\napi-v6\` 下只有 `win32\x64`，没有 darwin/linux。
- [ ] 便携版 `Simple-Music-2.6.1*.exe`（portable）同样能生成并启动。

## 2. 覆盖安装（手动运行安装包）

- [ ] 2.6.0 运行中时运行 2.6.1 Setup：安装器能提示/关闭旧进程，安装目录沿用原目录（`allowToChangeInstallationDirectory: false`）。
- [ ] 装完启动版本显示 2.6.1；桌面与开始菜单快捷键仍指向新版本，没有重复快捷方式。
- [ ] 登录状态（网易云/QQ）、播放队列与断点、设置、应用背景、歌单都保留。
- [ ] 播放网易云与本地歌曲正常；歌词页、桌面歌词、迷你播放条正常。
- [ ] 原生模块：AI K 歌生成一次伴奏（onnxruntime 能加载）；打开桌面歌词，原生毛玻璃背景正常（koffi 只用于 `windows-lyrics-backdrop.ts`，加载失败时背景会退化）。
- [ ] 默认伴奏目录在安装目录旁的 `Accompaniments`（便携版在 exe 同级），可写。

## 3. 应用内更新（本次改动重点）

在 2.6.0 或已装的 2.6.1 上，让应用检测到更新的版本（正式发布后用真实 Release；发布前把假版本号的 Setup.exe 放进下载目录无法走完整下载流程，至少验证安装段）：

- [ ] **启动检查**：启动后能检测到新版本并出现更新横幅。
- [ ] **定时/回前台补查**：应用开着时检测到新版本（定时 6 小时、回到前台距上次超过 1 小时会补查）；可把系统时间往后调或改小间隔的开发构建验证，至少确认最小化→恢复不会每次都请求（1 小时内只查一次）。
- [ ] **下载**：进度、取消、失败换线路正常；下载完成后 `updates\downloads` 里**只剩这一个安装包**，旧的 Setup.exe 被删除，进行中的 `.download` 不受影响。
- [ ] **安装**：点「重启并安装」后应用退出，NSIS 静默安装（`/S --force-run`），完成后自动拉起新版本；全程无 UAC 弹窗（perMachine: false）。
- [ ] **安装后清理**：新版本启动后，`updates\downloads` 里不比当前版本新的 Setup.exe 被删除。若安装器进程仍占用文件导致首次删除失败，确认只是日志告警、不影响启动，且下次启动会删掉。
- [ ] **按钮文案**：Windows 上为「重启并安装」/「正在安装…」（2.6.1 去掉了 mac 专属文案，确认 Windows 不受影响）。
- [ ] 便携版点更新时的行为与 2.6.0 一致（不应写坏便携目录），记录实际表现。

## 4. 背景图缩图（Windows 上的 nativeImage）

- [ ] 导入一张长边 > 3840 的 JPEG 和 PNG：保存到 `%APPDATA%\Simple Music\backgrounds` 的文件长边为 3840，显示正常。
- [ ] 导入一张手机竖拍照片（带 EXIF 旋转）：保存的是原图（尺寸不变），显示方向正确、没有横过来。
- [ ] 把一张超大 JPEG 以已有背景 id 的文件名放进 `backgrounds` 后重启：启动后被原地缩到 3840，设置里的背景仍然生效。
- [ ] GIF、WebP、视频背景导入后保持原文件。

## 5. Apple Music（若 Windows 上可用）

- [ ] 登录 Apple Music 后关闭 Apple 平台：后台官网页面被销毁（任务管理器里对应渲染进程消失、内存下降），状态显示「已登录」/「已暂停」，不弹授权窗口。
- [ ] 重新启用：显示「连接中」，几秒后静默恢复播放能力，不需要重新授权。
- [ ] 关闭状态下重启应用：不自动打开后台页面；再启用后能静默连接。
- [ ] Apple 歌单预览与列表显示完整曲数，总数未知时不显示「0 首」且按钮可用。

## mac 已验证（供对照）

- arm64 dmg 162MB；asar 内容干净；onnxruntime、koffi 在打包应用内可加载。
- 在 2.6.0 上覆盖安装 2.6.1 正常；真实配置下登录保留、背景文件未变。
- 原地替换 2.6.1→2.6.2→2.6.3 成功，新版自动拉起并提示一次「已更新到 vX」，旧版备份、暂存与安装包均被清理；同版本 dmg 回退为打开安装包。
- 打包实测发现并修复：Electron fs 把 `app.asar` 当目录导致旧版备份删不掉（改用 `original-fs`）。
- 未验证：Intel Mac（x64 dmg 只打包未运行）。
