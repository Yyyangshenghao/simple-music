# 2.4.0 内容延展左右留白

目标：`dev/2.4.0`；工作分支：`feature/content-gutter`。

内容延展下新增“左右留白”，每侧 16–64px，默认 24px；沿用现有滑杆，立即生效。切回保留边框沿用原布局并保留留白选择。设置写入宿主存档，旧存档使用默认值，异常数值在设置和读取时均限制范围。

验证：类型检查、全量 280 个测试文件 / 2634 项测试通过；独立代码复核无阻塞问题。真实 macOS Electron 开发模式使用隔离 userData，检查深色 1280×800 / 16px、浅色 900×800 / 64px，页面无横向溢出；宿主存储、界面重载、切回边框再开启延展均通过。未验证 Windows/Linux 实机。
