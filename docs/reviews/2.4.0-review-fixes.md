# 2.4.0 代码评审边界修复

目标：`dev/2.4.0`；工作分支：`feature/review-fixes-2.4.0`。

修复歌词播放控制样式遗漏后台命令、应用歌单多选入队误要求缓存歌曲来源在线，以及同 ID 曲目补详情后不重新获取歌词三个问题。多选只替换入队动作，下载与平台写入沿用原校验；歌词按请求依赖字段比较，跳转后仅对象、URL 或封面变化不清词，旧请求仍按会话和账号丢弃。

新增五项回归用例在修复前失败，修复后通过。类型检查、280 个测试文件 / 2639 项测试及两路独立代码复核通过。

真实 macOS Electron 开发模式使用隔离 userData 验证：

- 鼠标选择底部播放栏，确认后台状态和存档；原生最小化、恢复及界面重载后选择仍保留。
- 扫描真实本地静音 WAV，混选 QQ 已缓存、QQ 未缓存、本地与未登录 Apple 四首歌曲；后台真实队列回执确认仅追加缓存与本地两首，成功后清空选区。
- Apple 库占位曲目首次无词，同 ID 补出 `catalogId` 后真实歌词管线重取并显示；随后写入同曲新对象、实际曲目与进度不增加请求。
- 无页面运行异常，实际截图检查通过。

QQ 缓存状态与 Apple 歌词响应使用固定响应模拟，Apple 参与状态由测试注入；未验证真实在线账号、真实 QQ 缓存音频播放及 Windows/Linux 实机。本轮未打安装包、升级版本或发布。
