# 2.4.0 键盘行为收敛验收

目标分支：`dev/2.4.0`。普通界面控件只接受鼠标操作；键盘保留已配置快捷键、文字输入、快捷键录入和系统保留组合。

## 改动范围

- 主窗口捕获阶段先分发已配置快捷键，再阻止其余非文字输入按键，覆盖按钮、展开标题、分类导航、滑块、选择框、弹窗及页面固定字母键；不再保留刷歌方向键例外。
- 文字输入保留编辑、搜索提交与输入法行为，Tab 不移动焦点；快捷键录入继续支持 Tab、Enter 等按键。
- 主窗口、迷你窗口和桌面歌词共用普通控件的焦点框抑制样式，文字输入的焦点反馈保留。迷你返回绑定优先于聚焦按钮的默认操作。
- 删除主进程固定 Esc 退出全屏，避免抢走配置的按键。同步删除只为该固定操作服务的模态状态 IPC；播放宿主的弹窗快捷键阻挡和观察逻辑仍保留，原生菜单仅在快捷键录入时暂停。

## 验证

- 先扩展回归用例复现：原快捷键链路 16 项失败；原全屏按键用例更新后 5 项失败。修复后相关检查通过。
- `npm run typecheck` 通过；`npm test`：276 个文件、2595 项测试通过。
- 独立复核发现主进程 Esc 抢占，修复后复核通过；删除链没有残留 IPC 引用。
- `git diff --check` 通过；Impeccable 对变更界面文件的检查无发现。
- 使用 `npm run dev` 启动实际 macOS Electron 窗口，独立临时用户目录，通过 Chromium 远程调试发送键盘事件验证：
  - 聚焦普通导航按钮后 Enter、方向键、Home/End、PageDown、Esc、F/L 不触发控件。
  - 设置滑块的方向键、Home/End、PageDown、Enter 不改变值；原生排序选择框在收起与点击展开后，方向键与 Enter 都不改变值。
  - 深浅主题普通控件无 outline；搜索输入支持文字与光标编辑，Tab 不移焦。
  - 通过设置界面录入 Enter 为打开设置快捷键，聚焦其他按钮后仍能打开设置；录入 Tab 为迷你模式快捷键，Tab 进入并返回迷你窗口，迷你聚焦封面后 Enter 不误激活。
  - 全屏时 Esc 保持全屏，窗口退出全屏入口仍有效。
- 验证结束恢复临时用户目录的默认快捷键，没有修改用户日常使用的配置。
