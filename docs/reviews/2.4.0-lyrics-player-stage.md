# 2.4.0 普通歌词播放页

目标分支：`dev/2.4.0`；工作分支：`feature/lyrics-player-stage`。本阶段不升级版本、不推送或发布。

## 设计与范围

用户授权自行设计普通歌词页，解决播放栏隐藏时左侧单独下移、放大，以及封面、歌名、歌手在两处重复的问题。沿用 Simple Music 的字体、双主题和封面氛围，左侧以封面、曲目信息、进度和播放操作形成一个连续区域，右侧歌词使用相同的垂直空间。空闲只淡出操作，封面、信息与歌词不移动。

复用 `PlayerBar` 原有命令与控件，保留播放模式、红心、前后切歌、进度、音量、来源、桌面歌词、迷你条、队列及更多设置。普通歌词展开后不再重复显示底部播放栏；收起或切到 3D 时恢复。原有歌词定位、翻译、罗马音和排版设置继续使用。

封面自由位移限定于封面和信息，避免把播放操作带出窗口；左侧队列向右展开并覆盖在歌词上方。歌词设置按整个侧轨居中，翻译和罗马音按钮同时出现时也留在窗口内。菜单展开与键盘聚焦保持控件可见，侧轨支持焦点揭示。暗色普通 LRC 去掉透明度叠乘，改善非当前行可读性。

## 验证

使用真实 macOS Electron 开发窗口及隔离 userData；两首本地静音 WAV 与 LRC、测试封面用于交互和截图，不使用真实音乐账号。默认窗口 1536×864；最小内容视口由 CDP 设置为 960×540，截图来自实际 React 界面。

- 空闲前后封面、元信息、左栏与歌词列的矩形位置和尺寸相同；操作淡出后不可交互。
- 真实后台播放/暂停、切歌、进度键盘操作通过；队列和更多菜单空闲时保留，键盘焦点不会被隐藏。
- 默认、封面主导、歌词主导及最大封面位移检查通过，操作仍可点击；长歌名、无封面、无歌词无横向溢出。
- 最小窗口的队列、更多及同时包含翻译/罗马音的歌词设置弹层完整可见。系统减少动态与应用减少透明度设置生效。
- 普通歌词、3D 与收起切换通过。并行基准开发进程曾使共用依赖预打包缓存产生两份 React，停止基准并重启后恢复，无需改动 3D 实现。
- 类型检查、262 个测试文件的 2274 个测试通过；一次局部设计检测无发现。独立代码与截图复核覆盖本阶段实现及修正。

未在 Windows/Linux 实机或真实在线音乐账号下逐项验收；音源能力与播放执行沿用现有通路。机器记录见 [交互验收](2.4.0-lyrics-player-stage-verification.json)。
