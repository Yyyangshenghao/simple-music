# Windows 安装位置与流程优化

目标版本：`dev/2.7.0`。工作分支：`feature/windows-install-flow`。本地包仍使用源码版本 `2.6.2`，未升级版本、推送或发布。

## 修改范围

- 直接进入位置确认页，省去空欢迎页；统一中文字体、浅色标题栏和完成文案。
- `D:`、`D:\`、`D:/` 都解析为 `D:\Simple Music`；普通父目录补品牌子目录，已有受管理目录沿用原位置。
- 输入和浏览实时显示实际安装目录，长路径可换行、选择和复制。无效输入在当前页提示并禁用安装；目录冲突解析与安装使用相同函数，最终位置变化时要求再次确认。
- 卸载页显示程序位置、额外文件和播放器数据的处理范围，区分显式 `--delete-app-data`。
- 修复自定义脚本混用路径分隔符导致 Windows NSIS 找不到包含文件的问题。路径函数延迟到公共定义就绪后展开。
- 保留逐文件归属检查、解压校验、文件备份与失败回滚、旧版目录迁移和卸载保护；旧版迁移状态在最终路径确认后重建，预览不改注册表或创建目录。

## 验收边界与手工检查

维护者表示自行操作，已停止界面自动化。最后打开的 `Simple-Music-before.exe` 是旧版对照，不是最终测试包。最终布局修正后的截图、悬停/按压连续反馈、长路径、浏览取消、错误态、卸载页及完成页均待维护者检查。

请使用 `dist/Simple-Music-2.6.2-Setup.exe` 检查：默认路径、`D:/`、普通父目录、已有同名文件夹、系统目录拦截；确认显示的位置与实际落盘一致。安装后核对程序和快捷方式，再覆盖安装、卸载，确认额外文件仍保留。

完整安装、占用回滚、联接保护、旧版迁移和卸载的集成脚本仍只允许在一次性 Windows CI 环境运行。本次增加父目录/正斜杠实际安装断言，并将路径函数验收接入 Package 工作流；尚未运行远端 CI，也未验证全用户权限提升及真实应用内更新交接。

## 品牌与视觉继续优化

维护者要求移除旧图标并提高安装器视觉质量。检查发现 `installerHeader.bmp` 与 `installerSidebar.bmp` 内嵌的是旧紫色声波图标，当前 `icon.png` / `icon.ico` 则是耳机图标。

- 改为从 `icon.png` 生成顶部横幅与浅色品牌侧栏，三倍分辨率支持缩放；生成脚本为 `build/generate-installer-artwork.ps1`，只使用 Windows 自带 System.Drawing，不增加运行依赖。
- 在 electron-builder 配置中显式指定安装、卸载、顶部与侧栏素材，避免隐式回退或品牌混用。
- 将紫色进度和目录预览统一为蓝灰强调色；安装/卸载完成页统一字重、正文颜色，去掉底部重复版本文字。
- 修正卸载完成页文案的 NSIS 宏位置，让标题与保留文件说明在实际卸载页生效。
- 素材图已静态检查，安装/卸载回归 9 项通过；重新生成 NSIS 包。遵循维护者自行操作的要求，没有再次启动或操作安装窗口，最终视觉及高 DPI 交互验收仍待维护者完成。
