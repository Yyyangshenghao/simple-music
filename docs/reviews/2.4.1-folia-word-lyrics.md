# 2.4.1 逐字歌词补全与跃字展示

目标分支：`feature/folia-word-lyrics` → `dev/2.4.1`。参考本地 Folia 的平台逐字来源、保留逐行回退及 waiting/active/passed 展示思路，沿用本仓库的歌词类型、同曲匹配、媒体时钟与原生动画实现。

## 行为

- 首次返回普通歌词；QQ 手机接口的 QRC 在后台单独请求并解密，缺数字 ID 时由 MID 查详情。逐字服务慢或失败不延迟首次展示。
- 缺少真实逐字时，依次尝试本曲补全与已参与的网易/QQ 同曲版本；AMLL 查询 QQ MID 与数字 ID。歌手、版本、ISRC、曲长及歌词结束时间存在冲突时拒绝替换，切歌和账号变化丢弃迟到结果。保留用户歌词偏移与原音频来源。
- 跃字使用旋入、演唱放大、唱后回落和独立辉光，同一句重复进入保持姿态一致；长句缩小字号、按词组换行。暂停和窗口隐藏停止帧循环，拖动与偏移直接定位。减弱动态、关闭逐字动效、极短句直接显示全文。
- 本地 LRC 不自动换源。无真实逐字时仍只估算跃字展示节奏，无法保证与每个演唱音节精准同步。

## 验证

类型检查通过，全量 307 个文件、2897 项测试通过。回归覆盖 QQ 密文解码和失败回退、首次逐行与后台逐字拆分、AMLL 双 ID、同曲错配与结束时间越界、取消/账号迟到结果、偏移保留及动画回退和释放。独立复核的两项问题（可选 QRC 阻塞首屏、全局缓动导致长音提前回落）均已修复并复核关闭。

匿名公开曲目 QQ MID `0032UZe62rZk9K`：一次普通请求约 109ms，73 行歌词；仅给 MID 的后台请求解析到数字 ID `231729922`，返回 73 行、523 个逐字片段和 73 行翻译。该单曲只证明链路可用，不代表全部曲库覆盖或普遍响应时间。

macOS Electron 开发实例使用独立 userData 和自制歌词验证，无真实账号与音频播放。检查脚本见 [folia-word-lyrics.cjs](checks/folia-word-lyrics.cjs)，覆盖深色 1536×960、浅色 960×720、中英文长句、暂停、反向拖动、长音保持及系统减弱动态；无窗口溢出或页面异常。结果见 [verification.json](assets/2.4.1-folia-word-lyrics/verification.json)。Windows/Linux 与真实音频听感未实机验证。

## 第二阶段：动态海报

用户选择构图变化明显的动态海报方向。参考 [Folia 的错落分句](https://github.com/chthollyphile/folia-major) 与 [Codrops 的文字揭示实验](https://github.com/codrops/OnScrollTypographyAnimations)，保留应用字体、封面配色、现有播放操作与歌词数据通路。

- 短句使用聚焦大字，中句分为两段错落，长句沿标点和演唱停顿分为三段。字号、对齐方向、轻微倾斜与重点色形成句内主次；原始逐字 token 不拆分、不变序。
- 不同构图分别使用折入、侧向揭示、上升旋入。唱后保留正文，重点行带描边回声；轻微推移和缩放由同一媒体时钟控制，不增设独立墙钟。暂停、拖动、隐藏和减弱动态沿用原有控制。
- 以有限七步试排寻找最大可用字号，兼容窗口缩放、大字号、中英文长词与运行中切换翻译；不观察自身字号变化，避免 ResizeObserver 循环。

类型检查及全量 308 个文件、2904 项测试通过。独立复核校验 84 组分句边界，并关闭翻译切换后适配问题。实际 Electron 检查覆盖三种构图、960×720、1.8 倍字号、长音、反向拖动、关闭逐字动效及系统减弱动态；结果见 [verification.json](assets/2.4.1-pop-poster/verification.json)。
