# 2.4.0 应用歌单手动同步网易云

目标：`dev/2.4.0`；工作分支：`feature/app-playlist-netease-sync`。用户确认手动单向同步、漫游先保存为应用歌单。本阶段不升级版本、不推送或发布。

## 行为

- 「我的库 → 应用歌单 → 歌单详情」新增同步入口。全部曲目来自网易云且已登录、启用网易云时可用；混合音源明确禁用，不筛掉其他来源后偷偷同步。
- 首次创建私密网易云歌单，后续更新同一份的名称、曲目和顺序；不同账号分别记录关联。应用编辑不自动写云端，修改后显示待同步。新空歌单不创建云端目标，已关联歌单删空后允许明确点击清空云端曲目，歌单本身保留。
- 同步按差集分批补歌曲，回查新增完整后才移除旧曲目，显式排序后再回查完整结果。失败保留目标供重试，旧成功标记失效，不能误报已同步。账号变化、删除或同步中的本地编辑不会被迟到回复覆盖。
- 漫游每次生成独立应用歌单，落盘成功后才结束生成；「管理与同步」进入相同详情。旧本地快照首次打开漫游时迁移一次，已删除的关联不重建；旧云端漫游仅只读恢复，由用户主动导入，继续保留原云端歌单。
- 删除应用歌单只删除本地内容，不删除已经同步的网易云歌单。存档保留账号 ID、云端 ID 与成功快照，不保存 Cookie 或会话凭证。

## 验证

类型检查、264 个测试文件的 2295 项全量测试及独立复核通过。回归覆盖来源资格、本人普通歌单限制、账号凭证与中途换号、重复请求写锁、创建响应检查点、失败重试、漏歌保护、显式顺序回读、870 首分批、已关联空歌单及目标已删除/网络失败边界；本地覆盖持久化、并发编辑、删除、换号、超时失效及漫游新旧保存语义。旧自动写云端的漫游用例按用户确认的新行为替换。

真实 macOS Electron 开发窗口、隔离 userData；通过 API 测试响应模拟网易云账号和写入结果，未操作真实账号。默认 1536×864 与 CDP 960×540 内容视口验收：首次同步资格、失败重试复用目标、实际点击重命名和排序、刷新后关联保留、混合来源禁用、漫游本地生成及管理跳转、空列表更新、换号独立关联、退出后禁用、旧本地迁移/删除不重建，共十项通过。窗口截图来自实际 React 页面；服务端远端调用由路由回归测试验证。

独立复核提出的创建检查点丢失、新漫游错误复用编辑结果、删除被水合撤销、失败保留旧成功标记，以及空目标已删时重建空歌单问题均已修正并回归。创建检查点在当前服务进程内最多保留 64 条；正常收到回复后，云端关联由应用歌单持久保存。

未使用真实网易云账号实测写入，未在 Windows/Linux 实机验收。上游风控或网络失败仍可能导致部分写入，界面会报告未完成并支持重试。机器记录见 [交互验收](2.4.0-app-playlist-netease-sync-verification.json)。
