# 2.4.0 应用歌单手动同步网易云

目标：`dev/2.4.0`；工作分支：`feature/app-playlist-netease-sync`。用户确认手动单向同步、漫游先保存为应用歌单。本阶段不升级版本、不推送或发布。

## 行为

- 「我的库 → 应用歌单 → 歌单详情」新增同步入口。全部曲目来自网易云且已登录、启用网易云时可用；混合音源明确禁用，不筛掉其他来源后偷偷同步。
- 首次创建私密网易云歌单，后续更新同一份的名称、曲目和顺序；不同账号分别记录关联。应用编辑不自动写云端，修改后显示待同步。新空歌单不创建云端目标，已关联歌单删空后允许明确点击清空云端曲目，歌单本身保留。
- 同步按差集分批补歌曲，回查新增完整后才移除旧曲目，显式排序后再回查完整结果。失败保留目标供重试，旧成功标记失效，不能误报已同步。账号变化、删除或同步中的本地编辑不会被迟到回复覆盖。
- 漫游每次生成独立应用歌单，落盘成功后才结束生成；「管理与同步」进入相同详情。旧本地快照首次打开漫游时迁移一次，已删除的关联不重建；旧云端漫游仅只读恢复，由用户主动导入，继续保留原云端歌单。
- 删除应用歌单只删除本地内容，不删除已经同步的网易云歌单。存档保留账号 ID、云端 ID 与成功快照，不保存 Cookie 或会话凭证。

## 2026-10-16 更新时误报歌曲列表不完整

用户更新已关联歌单时收到“云端歌单歌曲列表不完整”。同一开发账号只读检查复现：网易云列表及详情摘要 `trackCount:862`，详情却返回868条有效、不重复的 `trackIds` 和868条歌曲。不能把摘要数字与完整ID数严格相等作为同步前提。已安装 NeteaseCloudMusicApi 4.32.0 的包内文档 `public/docs/home.md` 明确以详情 `trackIds` 提供完整歌曲列表，`playlist_detail` 模块原样请求并回传该字段。本次没有推断6首差值的上游原因。

修复以有效且不重复的完整ID列表计算差集与顺序；摘要少计不再误拒绝，摘要数量大于ID数、列表缺失、无效或重复ID仍在任何写入前拒绝。新增歌曲后的核对、排序前核对、最终完整有序回查及账号保护保持原样。

先加入实际868/862场景、摘要少计的完整更新与异常列表回归，旧代码3项失败，修复后通过。`npm run typecheck`及全量269文件2494项测试通过；97项同步/排序/QQ相关回归通过，独立复核通过。独立临时资料目录、合成账号与内存平台响应的真实HTTP服务验收通过：摘要少计的幂等无写入、增删改名排序、数量不足写前拒绝；未读取真实凭据或请求平台网络。本次仅改服务端逻辑，没有界面改动。

原云端歌单的同步路由实测被自动审批拒绝，因为即使预期无写入，也无法可靠保证路由不会修改原歌单；该测试未执行，也没有间接重试。真实账号仅做读取，未修改任何原有云端歌单。修复后的真实平台写入仍未验收。
