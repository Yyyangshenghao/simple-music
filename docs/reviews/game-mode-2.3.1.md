# 游戏模式与托盘集成验收

日期：2026-10-05。目标分支：`dev/2.3.1`。本次从 `69e4921` 提取游戏模式与托盘增量；原工作区的更新日志、账号修复、打包调整及版本元数据未包含在本次提交中。

## 行为

- 播放栏、设置和托盘均可进入游戏模式，收起主窗口、迷你条与壁纸，暂停可视层及相关后台界面工作；保留音频、队列与已启用的全局快捷键。
- 托盘提供播放/暂停、上一首/下一首、静音及音量控制。桌面歌词沿用原开关，没有游戏模式专属歌词选项；已开启时自动降耗，退出时恢复原外观偏好。
- 从托盘显示主窗口会结束游戏模式并恢复完整界面；普通退出模式按进入前的状态恢复迷你条与壁纸。

## 本次验证

- 隔离分支类型检查及全量 **171 个文件 / 1,372 项测试**通过；测试数量对应本次独立增量，不沿用原工作区其他未提交改动的测试数量。
- 独立复审未发现新增阻断问题或遗漏的功能依赖，确认 IPC、全局快捷键、普通歌词开关与恢复链路完整。
- 使用临时独立 userData 启动 macOS Electron 开发窗口：播放栏进入模式后主窗口隐藏、主界面卸载；通过真实托盘菜单回调切换原桌面歌词开关，模式保持启用；选择显示主窗口后模式关闭并恢复界面，无页面异常。
- 本次窗口检查未验证实际音频播放、操作系统物理按键、右键菜单展开、Windows、Apple Music DRM 或 CPU/GPU/内存占用；这些项目仍需对应环境验收。本次未生成正式安装包或发布产物。
