# 下载队列入口与存储术语

目标分支：dev/2.6.0。

- 离线音乐工具栏增加“下载队列”，直接打开共用任务面板 download 分区。
- 主动保存并导出的动作统一“下载歌曲”；播放器保留的歌曲称“离线音乐”，已有缓存的保留操作称“保存为离线音乐”，取消保留称“取消离线保存”；临时播放音频称“自动缓存”。
- 同步歌曲行、播放器更多菜单、离线页、设置与播放帮助的名称和删除提示；清理或删除播放器副本时明确下载文件保留，不再笼统提示“本地文件已删除”。缓存缺失称“未离线保存”，不能据此判断独立文件是否已下载。
- 下载任务先固定离线副本再导出文件，导出失败也可能有离线音乐。此次只改入口和文案，未改调度、缓存、删除、目录或持久化逻辑。
- 类型检查和全量389文件/3628项测试通过，最终状态措辞修正后相关2文件/10项测试通过。独立术语复核发现的“未下载”误判已修正。
- 实际 macOS Electron 已观察离线页新入口并点击，确认任务面板“下载”分区选中；取消离线保存名称同步显示。截图保留在本轮工具记录中。未执行真实下载、取消保存或删除；设置/播放器所有状态、浅色和最小窗口未完整视觉复验。
