# 2.3.4 播放栏按钮悬停效果验收

目标 `dev/2.3.4`。当前修订基于 `ce8a67e`，移除普通按钮的玻璃悬停框，改为图标自身的反馈。本轮仅集成样式，暂不发布。

## 改动

普通按钮在默认、悬停和开启状态都没有底色、描边或阴影。悬停仅让图标变亮并轻微放大至 1.08 倍；点击反馈沿用原有 Motion 按压缩放。SVG 缩放与按钮按压、播放/暂停图标切换、音量波纹分别作用于不同节点。

中央播放键保留实体圆形和柔和阴影，去掉悬停时额外扩出的光圈。红心保留红色，已开启功能保持图标点亮，更多按钮的倍速/定时提示点保留。原按钮尺寸、业务行为、菜单定位和键盘焦点轮廓保持原样；减少动画时禁用新增的图标缩放。

## 验证

- 在开发模式挂载真实 PlayerBar，使用合成曲目、合成已登录状态、预填红心缓存和本地 SVG 封面。播放状态切换使用测试替身，仅验证图标切换，未播放在线音频；临时验收入口已移除。
- 1280 × 720 深色界面中，静音按钮实际 `:hover` 为真，SVG 缩放矩阵为 1.08；普通按钮的背景透明、边框 0、阴影 `none`、伪元素内容 `none`。32/36px 普通按钮和 46px 主播放键尺寸保持原样。
- 鼠标悬停主播放键时切换到暂停图标正常，只有柔和阴影，没有外扩光圈。随机模式、已开启桌面歌词和队列按钮保持透明；队列展开正常。
- 960 × 640 浅色窄窗口及减少透明度模式下，静音悬停没有底框且无横向溢出。更多菜单正常展开；切换 1.25 倍速并关闭菜单后，按钮仍透明，5px 提示点保留。
- 独立只读复审未发现阻塞问题，检查了图标动画、状态颜色、提示点、菜单层叠和减少动画规则。系统减少动画偏好及键盘焦点未独立实测。
- `npm run typecheck` 通过；全量测试 197 个文件、1624 项通过。Windows 原生窗口尚未实机复测；浏览器验收不包含真实音频、桌面歌词/迷你窗口 IPC 流程。
