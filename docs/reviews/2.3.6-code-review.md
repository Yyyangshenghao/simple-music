# 2.3.6 发布复核

## 发布来源

`v2.3.5` 已按 `dev/2.3.5` → master 创建固定标签，但 [Release 运行](https://github.com/Yyyangshenghao/simple-music/actions/runs/38132452710) 的 Windows 测试因两条 POSIX 路径断言失败，publish 跳过，未公开 Release。macOS 测试与正式打包成功。标签保留原样，用户明确授权由 2.3.6 承接发布。

`dev/2.3.6` 从该 master 创建，包含自 `v2.3.4` 以来的全部功能与修复；完整业务复核、漫游补充修复和界面截图见 [2.3.5 复核记录](2.3.5-code-review.md)。本轮仅补充跨平台测试修复及发布前源码检查，不更改产品交互。

## 补充修改与验证

- 关闭偏好测试按 `path.join` 计算预期路径，继续精确校验临时文件、目标文件、内容及权限。独立复核通过。
- 新增 PR（目标 master/dev）及 master/dev 推送的双平台类型检查、全量测试与源码构建。工作流使用只读权限，不接触生产签名凭据或发布安装包；YAML 和独立复核通过。
- [双平台预验证](https://github.com/Yyyangshenghao/simple-music/actions/runs/38132858216) 全部通过，Windows 路径断言已在真实 CI 环境确认修复。
- 本地类型检查、225 个测试文件 / 1,955 项测试、源码构建和发布元数据校验通过。发布 PR 与合并后的 master 同样执行双平台检查，打标签前核对通过。

## 验证边界

- Windows CI 测试使用 Electron 模拟对象，不能替代 Windows 原生关闭、托盘、全屏 Esc、无响应兜底和实际安装更新验收。
- 未测量真实 GPU 显存、功耗与长期切换场景的资源变化。
- master 分支保护、tag 来源门禁与 Release 并发限制仍未配置；不使用管理员绕过失败检查。
