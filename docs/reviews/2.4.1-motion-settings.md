# 2.4.1 动效控制评估与实现

目标分支：`feature/motion-settings-2.4.1` → `dev/2.4.1`。沿用设置页的「界面与窗口」与动效预设，不增加独立设置页。

## 控制范围

| 动效 | 主要开销 | 控制与关闭后的表现 |
| --- | --- | --- |
| 页面、弹层、共享封面往返 | 短时补间、布局测量及合成 | 新增「减少动态效果」，直接切换并完成已有有限动画 |
| 分类液态指示器、按钮回弹 | 弹簧与局部变形 | 随减少动态直接落位；保留点击与拖动功能 |
| 简介、帮助逐字显现 | 字符分段、多层 DOM 与逐字过渡 | 新增独立「文字逐字显现」；关闭后普通文本，不分段 |
| 普通歌词逐字高亮、简洁 DOM 叠层 | 逐字原生动画与逐帧进度定位 | 新增独立「歌词逐字高亮」；关闭后整行高亮，取消动画与帧循环 |
| 普通歌词换句、封面飞行及切歌退场 | 换句动画、滚动与封面补间 | 随减少动态直接定位；旧封面直接移除，不依赖动画结束 |
| 标题跑马灯、返回箭头、加载骨架等 CSS 动画 | 持续合成或周期性绘制 | 随减少动态停止，保留文本与状态反馈 |
| 切歌氛围色过渡 | 12 次全局颜色更新 | 随减少动态直接更新目标颜色并停止计时器 |
| 流体背景与鼠标跟随 | WebGL、流体计算与上下文资源 | 沿用独立开关；减少动态时卸载，切为静态渐变 |
| 卡片倾斜与光斑、标题流光、播放栏辉光 | 指针监听、补间、蒙版和能量采样 | 沿用独立开关；减少动态时暂停，保留原选择 |
| 歌手工具栏跟随滚动 | 功能性滚动时间线 | 保留，保证吸顶与搜索、分类入口定位正确 |
| 3D 歌词场景 | Three.js 渲染、粒子与音频响应 | 保留独立「启用 3D 歌词舞台」；总开关不卸载场景 |
| 桌面歌词、壁纸、迷你条 | 各自窗口与渲染器 | 沿用各自设置；本次不增加跨进程控制契约 |

不是所有动画都持续耗 CPU。优先释放流体 WebGL、歌词逐字任务和音频辉光，短时转场与文字节点作为低配用户的补充选择。不会改变播放时钟、音频处理、虚拟列表或功能性滚动逻辑。

## 设置行为

- 标准：原有六项装饰效果、文字显现和歌词逐字高亮开启，减少动态关闭。
- 简单：静止背景、关闭鼠标跟随与文字逐字显现，保留其他效果。
- 极简：减少动态开启，八项单独效果关闭；透明度与 3D 歌词仍独立。
- 总开关暂停单项效果并显示原因，不覆盖原值；关闭总开关恢复各项选择。
- 系统减少动态优先，应用开关不能解除系统限制；系统与应用均可运行中切换。
- 旧存档新增项默认维持原表现；新开关自动保存，重载保留。

## 验证

定向单测覆盖旧存档、预设、持久化、暂停原因、系统联动、普通文本降级、歌词逐字动画与帧循环释放、氛围色计时器停止与恢复。`npm run typecheck` 与全量 295 个测试文件、2790 项测试通过，独立复核修复后通过；设计检测未报问题。

真实 macOS Electron 开发应用使用隔离 userData。脚本 [motion-settings.cjs](checks/motion-settings.cjs) 检查即时切换、在减少动态时挂载页面后恢复 Motion 动画、24 个歌词逐字动画全部清理、系统偏好联动、重载保留与歌手工具栏在滚动后定位到顶栏下方。

设置页同一场景各采样 3 秒，无播放、无 3D 场景，采样前回收 JS 垃圾：

| 指标 | 标准 | 减少动态 |
| --- | --- | --- |
| 渲染进程任务时间 / 采样时间 | 6.24% | 0.59% |
| JS 使用堆 | 20.37 MiB | 18.11 MiB |
| 流体 canvas | 1 | 0 |

这些是单次开发态样本，不是整机 CPU、进程内存或 GPU/显存统计，不能外推为所有电脑的节省比例。独立文字用例由 124 个 span 降为 1 个，24 个歌词逐字动画关闭后为 0。原始数据见 [verification.json](assets/2.4.1-motion-settings/verification.json)。

截图：[深色宽屏](assets/2.4.1-motion-settings/dark-1536.png)、[浅色最小宽度](assets/2.4.1-motion-settings/light-960.png)。界面无横向溢出或运行异常。未验证 Windows/Linux 实机、真实播放负载及整机资源节省。

独立复核发现并修复了两项回归：全局停动画误伤歌手工具栏吸顶；Motion 元素锁存减少动态配置后无法恢复。实际 Electron 检查脚本已覆盖两者。
