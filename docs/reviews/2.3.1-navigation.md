# 2.3.1 页面往返体验验收

目标分支为 `dev/2.3.1`；工作从该分支创建 `feature/smooth-album-return`，不涉及发布。

## 改动

- 页面级转场收敛为 180ms 短距离淡入淡出，探索页返回不再叠加标题、推荐和榜单入场。
- 探索推荐、个人栏目及歌手资料/热门歌曲预览/专辑/相似歌手同步复用近期缓存，先有内容再绘制滚动位置。缓存共用原有 64 条容量及账号失效边界；浏览数据 5 分钟，最近播放 30 秒。
- 推荐牌堆每个平台保留最近一份，保存分页游标，只有首页缓存对象仍有效时复用；Apple 精选复用同组推荐的抽样种子。
- 探索/库的详情由路由快照传入，退出页面保持原内容；详情背景仅由当前活动页面申请，旧页清理不能撤掉新背景，遮罩与封面一起淡出。

## 验证

- `npm run typecheck` 与全量 Vitest：183 个文件 / 1,460 项通过。
- 独立复审发现账号失效后预览继续分页、退出页迟到背景写入两个问题；均修复，后续复核无具体阻断。
- 隔离 `npm run dev` 页面使用 1,800ms 延迟和 40 张专辑，检查专辑详情返回、探索详情返回、设置页返回探索、换牌前后上下文与滚动位置、退出账号以及迟到背景响应。
- UI 证据使用受控数据，不代表真实平台网络或 Apple Music DRM 验收。截图：`docs/screenshots/navigation-2.3.1-explore.jpg`。
- 未构建安装包；首次访问、缓存过期和真实平台请求仍可能显示加载状态。
