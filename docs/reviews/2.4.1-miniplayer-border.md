# 2.4.1 迷你播放条外边框修复

用户报告 Windows 浅色背景下出现外圈边框。macOS 实际 Electron 透明窗口也复现了共用的矩形灰边：播放条与音量弹层使用 `0 8px 28px` 外阴影，但常态窗口只有 360×80、内容外留白仅 8px，阴影在四个窗口边缘被截断。

修复移除这两处外阴影，保留播放条自身圆角细线、底色及透明度。Windows 创建迷你窗口时补充 `thickFrame: false`，关闭默认原生厚边框；与已有 `frame: false`、`transparent: true`、`hasShadow: false`、`resizable: false` 配合，自绘宽度调整继续走原有 IPC 和 setBounds。macOS 不新增窗口配置。

## 验证

- Windows 配置回归先失败、修复后通过；同时覆盖 darwin/linux 不引入 Windows 专用选项，三种平台的自绘调宽行为保留。
- 类型检查与全部 295 文件、2801 项测试通过，独立复核无阻塞问题。
- macOS 实际 Electron、隔离 userData：浅色／深色／封面配色，音量弹层展开收回，自绘手柄从 360 调至 440，以及退出恢复主窗口均通过。弹层高度在 80／136 间切换时底边保持不动。
- DPR 2 的透明截图中，修前上／下／左／右最外沿 alpha 最大值分别为 11／44／23／24（0–255）；修后上述四种场景最外沿均为 0，不再残留矩形灰边。
- Windows 实机暂未验证，原生边框部分以构造选项回归及官方 `thickFrame` 契约为依据；未执行安装包构建。
