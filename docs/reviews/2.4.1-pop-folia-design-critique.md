## 结论与证据边界

**现有视觉方向不通过。** 已有实现能承担逐字展示，但字形装饰、句内层级和响应式构图尚未形成一致的设计语言。类型检查、测试数量和帧率不能代替设计验收。

本次采用两项隔离评估：A 为视觉与设计判断，B 为检测与证据核验。当前播放器未运行；判断来自实际查看的存档截图与现行源码。没有以本次实机播放验证音画同步、长时间观看感受或完整换句过程。动效问题中仅由代码推导的部分，下文明确标注，不能冒充实测。

目标文件：`src/components/Lyrics/PopLyrics.tsx`、`PopLyrics.module.css`、`src/lib/pop-lyric-layout.ts`、`pop-lyric-motion.ts`。本轮只评审及指导跃字，未对其他八种样式逐一作出通过结论。

## 五项返工要求

| 优先级 | 问题与依据 | 修改要求 | 视觉验收 |
| --- | --- | --- | --- |
| P1 | 强调段同时使用 850 字重、斜体、描边回声、辉光，字面拥挤 | 先关闭常驻回声与大范围光晕；沿用用户字体，用清楚的字面、大小关系和一个强调色建立层级；不能用换字体掩盖排版问题 | 暂停并关闭动效后仍有清晰构图；深浅主题均只有一套清楚的实体笔画 |
| P1 | 分段后仍由 CSS 二次折行，小窗出现被动尾行 | 按真实容器、字体测量及语义边界确定最终行；控制主句为有意安排的少量行；优先重新分配词组，再缩字号 | 同一文案在 960×720 与 1536×960 下都能自然读完；没有意外孤尾、裁切或挤压 |
| P1 | `accent = rows.length - 1` 固定强调末段；左右构图来自时间奇偶 | 取消“末段永远最重”；逐字演唱是主要注意力线索；句级层次依据自然分句、可信时间信息与稳定的少量版式建立 | 连续十句的重心有依据且不机械重复；跳回同句构图一致，阅读顺序明确 |
| P1 | 代码同时包含 65° 翻折、左右交替擦入、旋转上升、随机落姿、整句推移与复杂离场；实际节奏尚待录屏 | 先统一一种入场—演唱保持—回落语法，降低常驻随机歪斜；强效果不能每个字、每句话都触发；短句优先准确呈现 | 同版真实音频录屏中首字不迟到、长音不提前回落、快速连句不互相遮挡；暂停及倒拖能准确定位 |
| P2 | 译文随主句参与适配；下一句与译文缺少共同基准 | 给辅助文字稳定的区域与字号上限；降低下一句的视觉重量，保留阅读能力 | 同一暂停点开关译文，主句不明显缩放或跳位；长译文不撞播放条 |

以上动效归纳属于代码推断，不能以“已经实测卡顿／眩晕”对外表述。字距需要结合真实字面重新校准，避免 `.unit` 与 `.word` 的双层 padding 把中文词组拉散。

## 应该做成什么样

定位：**让文字像随着人声呼吸，当前演唱字是明确的视觉锚点，整句有稳定、疏朗的阅读结构。**

默认候选是 Folia `preview-lumi.png`（`classic`／流光）的连续字列与逐字重心。若用户更偏好分句错落，则以 `preview-tilt.png` 为单一主参考。先明确选用哪一项，不拼入云阶的引导线、心象的散置字场、商籁的故障效果或镜台的 3D 镜头。跃字是本项目自有名称，没有证据表明 Folia 存在同名对应模式；不得宣称一对一复现。用户已收到具体方向选项，答复优先于此默认候选。

借鉴的是空间密度、字的关系和演唱注意力的组织方式，保留项目字体、封面配色及主题。不得把用户希望模仿 Folia 理解为复制其专有素材或原封搬用源码。`tilt` 已是独立样式，跃字不能仅改名或直接重用倾诉后宣称完成重设计。

首轮先做一个代表样例：中等长度中文句＋真实逐字时间，完成无动效的排版，再完成一次完整演唱。可以用“让每个音符／都有自己的形状”作为跨窗口排版基线；最终仍需真实歌曲片段，不能只用自制文字验收唱感。

## 交给 Claude 的交付约束

1. 先提交一张参考与现状的对照板，注明每个参考的实际模式、借鉴点与不借鉴点；不要用“高级、电影感、神似”代替设计决策。
2. 先精修跃字，不扩大到所有动态样式。原有合并任务先收尾；新改动保持可审查，不顺带推送、升级版本或发布。
3. 第一轮交付相同文字、相同画布的前后截图，覆盖深浅主题、960×720、1536×960、长英文、长中文与长译文。
4. 交付 20–30 秒可重复观看的录屏，包含正常句、短句、长音和换句。以停帧看排版，以连续播放看节奏；没有听过的音画同步不写成通过。
5. 修复发现的问题后作一次确认；不能反复展示不同歌曲、不同时间点的单张好看截图来回避对照。代码验证与审美验收分别报告。
6. 第一轮只能称为待审版本；我会按参考接近程度、排版质量、演唱跟随性和观看舒适度检查，测试通过不自动代表视觉通过。

审美验收底线：暂停能成为成立的画面；播放能自然找到正在唱的字；大小窗口都没有偶然排版；长时间观看不靠密集特效维持注意。
