# 2.4.0 取消红心确认验收

QQ 与网易云的取消红心共用后台门禁。播放栏、歌曲列表、刷歌与快捷键先显示歌曲、歌手和所属平台，选择“取消红心”才写入；保留、Esc 或点击遮罩不提交。加红心保持直接操作。

成功取消一首后，30 秒内取消另一首，才提供“本次运行不再提示”。只有勾选并成功取消后生效，QQ 与网易云共用；仅保存在后台内存，主窗口重载不丢失，退出应用后恢复确认。登录账号变化时也恢复确认。失败不记入连续成功，不保存免提示选择。确认锁定原歌曲，不随切歌改变；重复入口和旧确认不会重复提交。

后台需确认时恢复主窗口，支持最小化、迷你模式和游戏模式。主窗口同步原生对话框状态，使全屏 Esc 优先关闭确认，保留现有快捷键屏蔽。
