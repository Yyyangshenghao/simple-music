# 2.4.0 文案与操作层级审查

目标：减少重复介绍与实现细节，让操作主次更清晰。审查基准为 `dev/2.4.0` 的 `7fe09aa`。本阶段先处理设置页，其余候选不代表已经实现。

## 首批：设置页

- 页面大横幅、英文装饰标签、导航编号、导航副文与分区副文重复表达“这是设置及其分类”。保留页面标题、六个分类和分区标题，减少连续说明与标题占位。
- 下载区正文列举批量、并发、暂停和重试，用户当前要决定的是下载位置与清理影响。删除功能清单，保留已有文件和下载目录不受缓存清理影响的边界。
- 游戏模式前后重复说明控制方式。合并成一处，保留音乐继续播放与托盘恢复途径。
- 独立动作与分段选项使用相同样式，更新、清理、恢复等操作缺少主次。使用独立动作样式，更新下载/安装突出，恢复与日志弱化，删除使用危险语义；不改变执行逻辑和确认流程。
