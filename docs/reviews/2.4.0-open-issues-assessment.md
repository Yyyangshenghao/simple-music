相关 [#44](https://github.com/Yyyangshenghao/simple-music/issues/44) 已关闭，其 QQ 横排阴影留白修复仍在；Apple 推荐组与专辑没有完整沿用，不能因 #44 已处理就认定 #63 同样修复。本轮复用该留白方案，并保留 QQ 原有横排行为。

实测还发现 Apple 专辑的 grid 子项默认最小宽度会撑开较窄页面，因此增加 `.albums { min-width: 0 }`，使滚动发生在横排内部。

## 验证结果

- 源码提交 `c893f57`：类型检查、256 个测试文件 / 2242 项测试、源码构建和独立复核通过。新增五项交互回归覆盖小步累积、行/页滚轮单位、边界放行、原生横轮/缩放保留、尺寸观察及清理、减少动画偏好。
- macOS arm64 的真实 Electron 开发应用中，实际 `ApplePlaylistRecommendations`、`AppleHomeLibrary`、Apple `ProviderPlaylistRail` 和 `Switch` 通过 22 项检查。数据来自只读缓存夹具，封面为自生成 SVG，无真实账号。
- 开启态圆点与轨道的样例对比度约为深色 16.49:1、浅色 15.52:1；开启、关闭与禁用状态均检查，原生点击仍传递布尔值。浅色关闭态保持原外观，不将其既有低对比度计为本次新增问题。
- 实际窗口宽度 960、1100、1700 下，页面没有被横排撑宽，ResizeObserver 正确更新溢出和按钮；无溢出时没有渐隐或按钮。应用最小窗口限制使请求的 820 宽实际为 960，未据此宣称测过 820。
- CUA 原生纵轮事件进入推荐横排后，实际 `scrollLeft` 从 0 到 844；原生下一页点击移动约视口的 85%。小增量、边界、Ctrl/Shift/deltaX 放行分别用合成 DOM 事件及单元测试检查，不代替实体鼠标或 Windows 实机验证。
- 已核阅四张截图。临时入口已删除，测试应用及端口已退出。未进行真实 Apple 登录、受保护播放或安装包验收。
