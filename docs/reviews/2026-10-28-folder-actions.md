# 音乐库文件夹入口调整

目标：dev/2.6.0。

- 本地歌曲行新增文件夹图标；通过索引 ID 查原文件，校验文件存在后在系统文件管理器中定位。渲染层不传路径、不解析音频 URL；文件缺失或目录打开失败有提示。批量选择时沿用原有精简行操作。
- 伴奏移除每行重复目录按钮，在工具栏设置左侧打开当前伴奏保存目录；离线页同位置打开实际 audio-cache 配置目录，齿轮定位缓存设置。
- 类型检查、388 文件/3627 项测试通过，独立复核无阻断项。覆盖索引查找、无效 ID、文件丢失、系统错误、UI 规范化 ID、提示和定位请求序号保护。
- 实际 Electron 已查看伴奏和离线工具栏截图，确认文件夹图标紧邻齿轮左侧；点击离线目录入口后，Finder 实际打开 audio-cache 目录。
- 当前真实本地库为 0 首，未导入或改变用户音乐库，因此本地逐曲行视觉与 Finder 原文件定位尚未实测；浅色、最小窗口和 Windows 未完整复验。单测不能代替这些验证。
