# 2.7.0 歌曲评论与歌曲精选验证

2026-11-05，目标分支 `dev/2.7.0`，接续[第一批平台内容](2026-11-05-platform-content.md)。本阶段增加网易、QQ 的只读歌曲评论和网易歌曲精选，其他内容候选保持在[版本范围文档](../specs/2026-11-05-platform-content-2.7.0.md)。

## 实现范围

- 网易、QQ 的共享歌曲右键菜单增加「查看评论」，当前曲目可从播放栏「更多 → 歌曲评论」进入。读取所选曲目自身来源，支持 QQ 数字 ID 与 MID，以及旧曲目仅保留 `id` 的情况。
- 评论页分别展示首屏热评和连续最新评论。分页使用上游页大小推进，去重、无进展终止和错误重试各有处理。正文按纯文本保留换行，日期异常时保留正文并隐藏时间。
- 评论页打开期间保留来源页；从歌单详情进入时也保留其上层浏览页，最多同时保留三页。评论曲目切换不累积页面，返回恢复原实例和滚动，离开阅读流程释放这些上下文。
- 网易 Banner 先筛选歌曲目标再限制五项，缺少内嵌歌曲对象时批量补详情，按原顺序展示。非歌曲与外链目标不进入歌曲精选，部分失败保留可用歌曲并提供重试。

## 自动验证与独立复核

`npm run typecheck && npm test` 通过，424 个测试文件、4031 项通过、2 项跳过。界面对齐调整后再次完成类型检查与评论页、入口、转场的针对测试。

回归覆盖热评不替代最新评论第一页、空热评、正文过滤后仍按请求页大小推进、QQ MID 补数字 ID、上游业务失败、账号/启停迟到响应、评论去重、坏日期、纯文本正文和返回来源层级。独立复核发现的返回上下文缺失已修复，最终转场复核未发现新问题。

## 真实接口与界面检查

通过 `npm run dev` 启动实际 Electron。网易歌曲精选返回五首可用歌曲，`partial=false`。网易评论首屏有 15 条热评、20 条最新评论，下一页 20 条最新；QQ 首屏有 14 条热评、19 条最新评论，下一页 19 条最新。两平台下一页均无首屏重复项，也不再重复返回热评。QQ 页偏移仍从 20 推进，避免因过滤正文后只有 19 条而重读同一页。

实际 Electron 中，从带 100 首真实周榜歌曲的验收详情深滚动至 800px，经共享歌曲菜单打开评论并返回，滚动仍为 800px，评论页读取到 20 条最新评论。

独立浏览器上下文加载相同开发渲染入口，使用构造内容验证两平台右键/播放栏入口、1440×960 深色和 960×720 浅色布局、首次加载、从 20 条翻至 25 条并终止、故障重试恢复、纯文本安全，以及精选播放集合只包含五首网易歌曲。未出现页面运行异常或页面级横向溢出。播放集合通过队列接收记录验证，未启动真实音频。
