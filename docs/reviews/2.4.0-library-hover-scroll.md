# 2.4.0 我的库悬停滚动保护

目标 `dev/2.4.0`，基准 `344d713`。库页歌单、专辑和收藏入口复用 `PlaylistCard → TiltCard → BorderGlow`，原先缺少探索页已有的连续滚动保护。

`ScrollArea` 新增主动启用的 `pauseCardEffects`，仅在库页开启；滚动状态在容器内部维护，子树引用稳定，不因滚动重建整个网格。复用现有 wheel/scroll 观察、180ms 停止恢复和清理逻辑。BorderGlow 通过通用 `data-scrolling` 识别暂停；探索页卡片自身的 TiltCard 同样带此标记，保护继续有效。其余 ScrollArea 默认行为、内层 VirtualList 状态和静止外观沿用原实现。

## 实测与验收

真实 macOS Electron 开发窗口 / Apple M5，独立 userData，1280×800、DPR 2；24 张网易云测试歌单及本地 PNG 封面。鼠标保持 x160/y350，发送 96 次原生 wheel，每次 ±25px、间隔 16ms，每 24 次反向。前后均收到 96 个 wheel、96 个 scroll，累计位移均为 2400px，结束位置为 0；未触发 pointermove。

| 累计开销 | 修改前 | 修改后 |
|---|---:|---:|
| 样式计算 | 210.47ms | 77.94ms |
| 布局 | 39.77ms | 37.81ms |
| 绘制 | 85.78ms | 82.27ms |

这是同操作序列的一轮前后采样，显示悬停相关样式计算开销下降；不等同于完整用户体感或帧率结论。[机器结果](2.4.0-library-hover-scroll-verification.json)保留输入、事件数量与交互验收。

- 新增容器回归用例先失败、修改后通过，覆盖启用后的暂停/恢复/卸载和默认滚动阈值回调；全量类型检查、277 个文件 / 2,601 项测试通过。独立复核无阻断项，未做生产构建。
- [实际库页脚本](checks/library-hover-scroll.cjs)验证网易云、QQ 的歌单/收藏及 Apple 的歌单/专辑/收藏共 7 组场景：悬停、滚动暂停、光斑与辉光释放、停止恢复、滚动中点击进入详情、返回、偏好保留。短收藏页无实际位移的 wheel 也能恢复。
- 应用歌单未使用这套辉光组件；原探索页组件回归另行通过，覆盖旧卡片无上浮残留、暂停中点击、内部滚动和边界恢复。
