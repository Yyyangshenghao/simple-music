# B 站统一歌曲身份识别验证

日期：2026-11-06。工作分支：`codex/bilibili-song-identity`，基于 `dev/2.7.0`；按维护者授权以本地 Squash 方式集成到该 dev，未推送或发布。

## 行为与边界

- 从视频原题与简介提取读法，跨平台核验歌名、歌手、录音版本、时长与 ISRC。只知道歌名时要求候选歌手唯一，不用 UP 主冒充歌手。
- 当前播放项主动识别；列表和歌单拼贴只复用已有搜索结果与缓存。识别结果统一用于显示和歌词 ID，原曲 BV、来源及音频解析规则保留。
- 每轮平台识别或映射最多两个关键词；同身份的在途搜索共享，B 站自动取词串行、命中即停。失败识别有 60 秒自动重试间隔，账号或查询条件变化可重新识别。
- 多候选歧义拒绝自动关联；网络失败不记为曲库未收录。保留明确选择的 Apple/汽水与酷狗 KRC 的独立兜底路径。

## 开发版实测

以 `npm run dev` 启动开发版，通过实际界面输入公开 BV 号 `BV1GJ411x7h7` 并选择播放音频。

观察到原题“【官方 MV】Never Gonna Give You Up - Rick Astley”识别为规范歌名“Never Gonna Give You Up”和歌手“Rick Astley”；视频详情行及播放栏同时更新，并展示匹配到的专辑封面。原视频标题仍作为辅助信息保留。打开歌词页后，规范曲名/歌手与歌词正文正常显示。已检查实际界面截图，未改布局或交互样式。

本次实测只有一个公开视频样例，不能代表总体匹配率。没有逐项验证所有音源的真实歌词时间轴、迷你条/桌面歌词窗口、深浅主题和连续交互帧；这些同步行为有自动回归，但仍需后续抽样验收。此次歌曲身份识别不使用音频指纹，MV 前后对白、长前奏、剪辑与翻唱仍可能无法可靠关联。
