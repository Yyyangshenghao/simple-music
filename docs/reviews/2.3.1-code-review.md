## 已确认问题与修复范围

| 路径 | 问题范围 | 本轮处理与验证目标 |
|---|---|---|
| `server/lib/http.ts` | 中文及 emoji 的 UTF-8 字节被网络分片拆开时，逐片转字符串产生乱码 | 整体解码请求体，保留长度上限和 JSON 错误处理；新增多字节分片回归 |
| `src/stores/update.ts` | 更新下载轮询请求重叠，旧任务响应可能覆盖当前下载状态 | 串行轮询并隔离任务生命周期；停止或切换任务后丢弃旧结果 |
| `src/lib/api.ts` / `src/stores/provider-auth.ts` | 旧账号请求迟到的 401/403 使新账号被误判为失效 | 按请求发起时的账号上下文过滤鉴权失败；账号变化后丢弃旧结果 |
| `src/stores/likes.ts` | 账号变化遗留红心缓存、查询冷却与待查任务；同曲连续写入失败后回滚到错误状态 | 清理账号相关状态，同曲写入串行，按已确认状态回滚；覆盖双失败及跨账号排队 |
| 现行文档 | 架构、入口和验收状态漂移 | 已同步 IPC 契约与运行时共享纯逻辑、CSS 变量注册范围、缺漏的页面及主进程入口；旧性能验收明确标为历史批次 |

上述修复已实施。独立复审发现的红心连续双失败回滚问题也已修正；追加回归后的最终类型检查、全量测试与复审通过，不把这些结果扩写为所有异步或账号场景均已通过。

## 体积与界面优化

本轮已实施以下调整，体积数据与实测边界见验证部分：

- 渲染层由构建打包的依赖移至开发依赖，避免作为主进程运行依赖再次进入安装包；保留主进程直接使用的服务、媒体解析及原生依赖。
- 渲染构建显式启用 esbuild 压缩，移除没有应用调用入口的 FlowingMenu 及其 GSAP 依赖。检查运行时外部依赖与原生文件仍可用。
- `AppShell` 首次加载页面提供可见反馈；更新历史调整阅读留白与窄窗口布局，保留鼠标、键盘展开及当前版本标识。
- 安装包节省量待相同平台的实际打包结果验证；依赖数量、输出文件大小或单测时长不能代替安装包体积、启动速度或帧率结论。
