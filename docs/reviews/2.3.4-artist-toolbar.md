# 2.3.4 歌手页分类栏背景衔接验收

目标 `dev/2.3.4`，基于 `8ed3dba`。用户截图指出歌手页分类与搜索栏的整行黑色背景突兀。本轮只集成修复，暂不发布。

## 修正

原分类栏在页面滚动超过 8px 后显示全宽伪元素，实测背景为 88% 不透明的深色，且上边缘未渐隐；分类栏尚未吸顶时也会把封面氛围背景切断。

取消全宽背景，将玻璃承托限制在圆角标签组和搜索框。滚动后仅增强两个控件的局部底色，避免列表文字透入；标签、专辑和相似歌手复用同一容器。搜索框通过局部 CSS 变量接收背景与模糊，其他页面的默认、悬停及聚焦值保持原样。减少透明度和减少动画仍遵循现有设置。

## 验证

- 在开发模式中挂载真实歌手页、顶栏和播放栏，用合成 QQ 歌手、50 首曲目、20 张专辑与本地 SVG 封面复现截图；未登录在线账号。
- 1280 × 720 深色界面检查部分滚动与吸顶：整行背景伪元素已不存在，吸顶位置保持 52px；标签和搜索独立承托。
- 960 × 640 浅色窄窗口检查布局，专辑、相似歌手及热门单曲切换正常；减少透明度模式的背景模糊为 `none`，未恢复全宽横条。
- 独立复审未发现阻塞或其他搜索页面默认样式回归；复审指出局部减少动画声明顺序问题，已移到常规过渡声明之后。
- 最终 `npm run typecheck` 通过；全量测试 197 个文件、1624 项通过。Windows 原生背景合成尚未实机复测；本地合成数据验收不代表在线歌手资料请求已验收。
