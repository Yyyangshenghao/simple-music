这轮改进

  • 搜索页缩短页头，两层筛选整合，全部结果改为分区预览并保留完整分类入口。
  • 库、搜索与详情的内容起线统一，简介限宽，歌曲专辑列靠近正文，时长常驻。
  • 我的库外框恢复由页面布局设置控制；常规弹层与顶栏用途提示更一致。
  • 探索、漫游只调整比例与重复装饰，保留现有音乐内容和风格。

保留的边界

  • 960×540 的全部搜索仍需滚动越过歌手预览，不能视为所有歌曲都能首屏可见。
  • 歌单详情的小窗口首屏仍以封面与信息为主；普通歌词、设置与播放栏未重构。
  • 平台数据与封面为明确的模拟 fixture；不是实际账号、真实音频或 Windows 验收。
  • 流体氛围存在少量像素噪声；推荐卡日期取拍摄当天。像素差异不等同设计质量。
  • 补充检查观察到删除应用歌单弹窗按 Esc 未关闭；重复导航的歌手页滚动探针也有未定因疑点，详见验收文档。
