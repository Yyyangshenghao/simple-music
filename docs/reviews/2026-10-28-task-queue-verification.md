# 任务队列重设计验收

对应 [设计稿](../specs/2026-10-28-task-queue-bubble-design.md)，实现于 `feature/task-queue-bubble`，基于 `dev/2.6.0`。

## 实现范围

- `task-center` 只持有主窗口界面状态；观察后台任务快照，不合并两套调度器。入队和冷启动恢复不自动弹面板，恢复任务保持暂停。
- 头像旁按需浮现统一入口，槽位与圆钮共用弹簧；最新入口使用 12px 轻移与淡入，不再模拟连接颈部；入场和按压分层。关闭「队列动效」或系统减弱动态时保留平滑槽位与淡入淡出。
- 下载、伴奏两分区共用任务行，按状态分组，批量动作与目录移入对应位置；分区高度随内容平滑变化，减少空白和瞬时跳动。
- 完成结果按分区记录已读；全部收尾后驻留 90 秒，查看结果后关闭融合；失败与恢复错误持续保留入口。伴奏完成记录在后台内存中最多保留 50 条，不写盘；删除成品同步移除记录。
- 设置、库页、播放页入口统一改接。任务入队时间与启动时间随快照传递，确保同一批快照内两队列运行时按实际启动时间选择图标和进度。

## 交互打磨验收

按后续要求将所有生成任务管理收进专门队列，伴奏成品页及麦克风面板不再重复进度、取消或重试。队列增加任务定位高亮、分区滚动恢复、跨组行移动、异步忙态与去重、错误分区归属，以及面板先收回再融合的连续动作。

- 最终 `npm run typecheck`、382 个文件 / 3569 项测试全部通过；增量独立复核通过。
- 实际 Electron 临时投影验证：入队不弹面板；目标任务位于可视范围；双击仅一次重试；跨组后仍是同一行元素；分区滚动 230px 往返后仍为 230px；迟到错误仍归属原分区。
- 暂停后展示继续操作；Esc 先收更多菜单；批量取消等待保留当前生成任务和失败项；完成项播放传入正确伴奏身份；清除完成记录不删除成品。
- 逐帧验证关闭过程中面板不可点击，入口保持展开至面板退场后再融合；系统减弱动态运行中切换后，连接颈部移除且按钮无空间变换。全程没有界面脚本错误。
- 深浅主题、1440×900 / 960×680、定位高亮、空态及减弱动态截图见 [交互打磨截图](assets/2026-10-28-task-queue-polish/)。原始交互与逐帧数据见 [interaction-verification.json](assets/2026-10-28-task-queue-polish/interaction-verification.json)。
- 此轮机械设计检查无提示。交互脚本仅替换主窗口展示数据与操作回执，结束后恢复原状态，没有启动真实文件下载、伴奏推理或删除操作。
