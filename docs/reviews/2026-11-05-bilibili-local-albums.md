# 2.7.0 视频直达与本地专辑验证

2026-11-05，目标分支 `dev/2.7.0`，第三批平台内容扩充。范围与后续候选见[版本文档](../specs/2026-11-05-platform-content-2.7.0.md)。

## 实现范围

- 全局搜索识别 BV 号、官方完整视频链接与含此类链接的分享文字，直接打开 B 站音频详情，不把视频输入发送给其他平台的普通搜索。未启用 B 站时提供音源设置入口，不读取详情。
- 详情保留视频原题与 UP 主，支持游客播放与加入应用歌单。多集视频使用首 P 并明确提示；短链接、指定非首 P 和非法链接显示原因。详情请求固定上游，复用游客风控和有界 CID 缓存，不抓取用户输入的 URL。
- 本地音乐增加歌曲/专辑切换、封面分组与组内筛选播放，沿用多选、加入应用歌单和逐曲定位。返回专辑网格恢复滚动位置。
- 专辑按专辑名和专辑艺人分组，无专辑艺人时回退曲目艺人，缺少专辑标签显示「未分类」。新索引保存 `albumArtist`，旧索引可显式重新扫描补齐；未变文件仅补该字段，解析失败保留原记录并允许后续重试。原文件与曲目 ID 不变。

## 自动验证与复核

`npm run typecheck && npm test` 通过：429 个测试文件，4070 项通过、2 项跳过。覆盖链接解析与拒绝规则、固定上游详情映射、首 P 时长、来源启停隔离、合辑分组、同名专辑区分，以及旧索引补字段成功、失败保留和再次重扫。

独立复核发现的旧索引解析失败可能降级原元数据问题已修复，并补充回归测试；最终复核未发现阻塞问题。

## 真实读取与界面验收

隔离 HTTP 服务读取真实游客视频 `BV1GJ411x7h7`，返回原题、UP 主、213000 毫秒时长和 9 个音频候选。没有实际播放这些音频。

隔离目录生成 5 个带标签的真实静音 FLAC，经过本地 HTTP 扫描得到 4 张专辑：两首不同单曲艺人的合辑正确合并，两张同名但不同专辑艺人的专辑分开。删除隔离索引中的专辑艺人字段后重扫，标签恢复且 ID 不变。未修改用户音乐文件或真实索引。

使用 `npm run dev` 的渲染入口，在独立浏览器上下文以构造数据检查：B 站直达与未启用状态、503 后重试恢复、链接未发送给其他平台搜索、加入应用歌单；本地首次读取失败后恢复、30 张专辑展示、四首合辑播放集合、筛选后仅一首的播放集合、批量加入应用歌单、定位只传索引 ID，以及返回网格滚动保持 300px。无页面运行异常。

播放集合通过队列接收记录验证，定位通过桥接回执验证，未验收实际出声播放与 Finder 打开文件。Apple 真实账号和受保护播放验收缺口沿用第一批。
