# 普通下拉组件验收

目标分支：dev/2.6.0。

- 新增 Select，统一离线排序、伴奏版本、歌词测试曲、歌词记忆排序/单曲来源/批量来源六处普通单选入口；字体搜索选择器保留专用交互，播放探针测试页保留原生控件。
- 与现有主题和字体一致，选中勾选、禁用项、长名称换行、外部点击与 Esc 关闭、窗口避让、父级滚动关闭；浮层以 dialog 子孙进入 popover top layer，规避模态 inert、滤镜包含块与裁剪。
- 弹层与箭头分别使用 popoverSproutMotion / iconMotion 和现有弹簧，系统减少动态即时切换；减少透明度时使用纯底色。退出期间禁止点击，快速重开恢复点击。
- 类型检查和全量 387 文件、3614 项测试通过；包含视口边界、禁用与值回调、动效降级、Esc 捕获和监听清理回归。两份歌词设置测试保留来源范围与批量失败行为断言。
- 独立复核发现的 Esc 捕获层级、背景透明度与重开 pointerEvents 问题均已修正。
- 实际 macOS Electron 深色界面检查：伴奏版本菜单可打开并切换版本；歌词来源原生 dialog 中排序菜单不被遮挡，选择按歌名后正确更新，Esc 后父弹窗保留。修正了 dialog button 字体规则覆盖菜单选项的问题。截图见本轮工具记录。
- 未完整验收：浅色/减少透明度的实际截图、960×540、长列表滚动和快速重入连续帧、Windows。定位与动效单测不能替代这些视觉验收。
