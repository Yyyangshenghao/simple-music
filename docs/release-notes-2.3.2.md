## 更新日志

- 新增：游戏模式与托盘控制、Windows 关闭窗口选择、离线更新日志；支持专辑及歌单搜索、搜索历史与详情简介。
- 新增：下载队列与独立歌曲目录，支持并发下载、暂停、取消和重试；离线音乐支持多选批量删除。
- 优化：多选加队列、框选及详情菜单，统一滚动条样式与交互、改善封面与路径显示并精简体积；禁用 Tab 遍历和普通方向键导航，空格优先播放。
- 修复：QQ 歌单加载、页面返回状态、每日推荐批量操作、队列清空及媒体同步，完善账号隔离；修正 Windows 文件名长度测试。

## 兼容说明

- 保留账号、队列、本地音乐与用户设置格式。
- Apple Music 仍使用独立受保护播放会话，不参与跨平台音频替换或离线保存。
- 键盘导航调整保留输入编辑、快捷键录入、自定义绑定及爽歌上下切换。
- v2.3.1 的 Windows 发布测试失败，未生成公开 Release；保留原标签，2.3.2 包含全部已验收的 2.3.1 功能和修复。

## 验证情况

- 2.3.1 发布尝试中，macOS 工作流通过，Windows 有一项文件名长度测试失败，统一发布步骤因此跳过。旧断言用正斜杠拆路径，将 Windows 完整路径误当文件名；现改用平台原生 basename，长度阈值、目录归属、内容校验及生产下载逻辑均未改变。18 项下载回归、类型检查、196 个文件 / 1,620 项测试、源码构建及独立复核通过。
- 完整功能验收沿用 [2.3.1 验证记录](release-notes-2.3.1.md)：近期界面已在隔离 macOS 开发窗口验证；准确生产构建启动、版本显示和离线更新日志检查通过。用户确认 QQ 自建歌单加载与播放正常，#23、#24、#25 均已关闭；#24 按已确认范围完成，批量添加到歌单留待 2.4。
- 正式安装包以本版本 Release 工作流的双平台测试、构建、VMP 签名及产物校验为准。Windows 安装后的完整交互、真实安装升级和 Apple Music 受保护播放仍需真机验证。
