# 探索页模块设置

此功能属于 `dev/2.7.0` 开发内容，尚未发布。各音源可以独立选择探索页栏目及上下顺序；设置只影响本机的探索页，不修改平台推荐或平台账号内容。

## 入口与使用

打开「设置 → 音源与播放 → 音源与账户」，点击对应音源旁的齿轮。只有音源已启用、账号或游客会话可用且播放能力可用时，才能打开设置。停用后入口禁用，已有模块配置保留。

面板向齿轮左侧展开，覆盖到当前设置分组边缘：

- 左侧开关控制模块展示，拖动模块行调整上下顺序；更改自动保存。
- 右侧同步预览当前音源的实际探索内容，可独立滚动。预览为只读，不能播放、打开详情或拖动封面。
- 「恢复默认」还原当前音源的模块开关和顺序，不修改其他音源或地区、封面等平台专属设置。
- 点击关闭、按 Esc 或点击面板外部即可收起。窄窗口中内容内部滚动，拖动至上下边缘可连续滚动排序。

预览与正式探索页使用同一份模块配置和内容组件。内容随账号、缓存和上游结果变化，可能显示加载、错误或空结果；打开预览会按已启用模块正常读取平台内容。预览画布保留至少 1280px 的桌面排版宽度，再按面板宽度缩小，避免多卡片推荐挤压。

## 各音源模块

| 音源 | 默认模块顺序 |
|---|---|
| 网易云 | 推荐与发现 → 歌曲精选 → 本周常听 → 我的歌单 → 最近播放 → 排行榜 |
| QQ 音乐 | 推荐与发现 → 我的歌单 → 最近听过 → 排行榜 |
| Apple Music | 推荐与榜单精选 → 个人资料库精选 → 我的歌单 |
| 酷狗音乐 | 推荐与发现 → 我的歌单 → 排行榜 |
| 汽水音乐 | 继续听 → 已整理的歌单 → 主题歌单 → 听歌模式 → 我的歌单 |
| 哔哩哔哩 | 暂无探索页模块；齿轮保留「显示专辑封面」设置 |

「推荐与发现」是组合模块：网易含每日推荐、私人雷达与发现歌单；QQ 另含猜你喜欢；酷狗为发现歌单。Apple 的推荐与榜单精选也保留为组合模块。当前不提供组合内部的独立排序，不支持安装第三方插件。

汽水「继续听」来自本机最近播放，「已整理的歌单」来自包含汽水歌曲的应用歌单，均不代表官方账号曲库；「我的歌单」登录汽水账号后才显示。「主题歌单」通过游客搜索读取华语流行、民谣、电子和爵士歌单，仅加载当前主题。「听歌模式」直接展示默认、熟悉和新鲜，其他场景可从「更多场景」按图文浏览或搜索。点击模式直接开始播放，不展示歌单；队列快播完时自动补下一批，再点当前模式可暂停或继续。常用区最多 5 个，直接在探索页拖动调整：从「更多模式」拖上来固定，满了替换落点，拖回去取消固定。常用模式由服务端提前备好歌和第一首地址，切换时不必等上游。游客曲库有限，久听会重复；账号个性化效果待验证。其他平台账号条件及内容边界见 [平台功能地图](music-sources.md)。Apple 的地区选择、哔哩哔哩的封面设置继续保留在各自面板。

## 保存与边界

默认启用所有已有模块，保持原展示顺序。允许全部关闭，探索页会显示重新开启的设置路径。关闭的模块不挂载，不再发起新的栏目读取；已发出的请求不保证撤销，其过期响应不得覆盖新页面或新账号。

模块配置按音源保存在 `simplemusic-settings` 的 `exploreLayouts` 中，由后台设置命令 `setExploreLayout` 保存并随快照同步主窗口。重新打开窗口或重启应用后保留。旧存档自动补齐默认模块；未知或重复模块会被忽略，后续新增模块追加到末尾，保留已有开关和排序。配置按本机音源保存，不按平台账号分别保存；换号时预览内容重建，模块偏好不重置。
