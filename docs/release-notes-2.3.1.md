## 更新日志

- 新增：游戏模式与托盘播放控制，Windows 关闭窗口时可选择退出或缩回托盘。
- 新增：离线更新日志页面与可管理的搜索历史，补齐网易云与 QQ 歌手简介、网易云专辑简介。
- 新增：专辑与歌单搜索，支持多选歌曲或专辑追加播放队列、加入本人网易云歌单；歌曲、专辑和歌单支持批量下载。
- 新增：常驻下载队列，可选择歌曲文件目录、查看进度、暂停队列、取消和重试；默认沿用现有音频目录，保留原缓存配置和文件。
- 优化：本地下载支持三首并发与自动排队；专辑详情放大封面，封面从卡片平滑移动到详情，曲目列表去除重复封面。
- 优化：精简重复打包的界面依赖并压缩代码，改善页面加载、往返流畅度与窄窗口显示，完善使用文档。
- 修复：QQ 歌单加载失败、歌手页返回丢失标签和位置，以及中文及表情乱码、更新下载状态、账号切换后的登录与喜欢状态。

## 兼容说明

- 保留账号、队列、本地音乐与用户设置格式。
- Apple Music 仍使用独立受保护播放会话，不参与跨平台音频替换或离线保存。
