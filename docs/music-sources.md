# 平台功能与内容地图

核对日期为 2026-11-05，包含 `dev/2.7.0` 第一批内容扩充。这里描述开发版已接入的代码与界面，账号权益、上游可用性和真实播放仍需按来源验收。稳定版 `v2.6.2` 的在线平台注册范围为网易云、QQ 和 Apple Music。

当前开发版有六个在线来源，另有本地音乐。网易云、QQ 默认启用，Apple Music、酷狗、汽水和哔哩哔哩默认关闭。平台参与播放、账号登录、歌词来源分别管理。2.7.0 的增量建议见[内容扩充候选](specs/2026-11-05-platform-content-2.7.0.md)。

应用歌单编辑保存在本机，平台写入按目标平台、账号权限和歌单类型核验。QQ 暂无歌单可见性切换。应用的最近播放与平台历史分别读取，不能混写成官方账号历史。

刷歌按首选可用来源取候选，当前没有为每个平台建立独立推荐算法。汽水虽能参与来源选择，但现有服务返回空推荐，不能据此宣称已支持有效刷歌。B 站无账号会话，也没有推荐供给。漫游中的“可取歌曲池”也不等于有歌手关系网。

代码入口见[歌单管理](../src/lib/platform-playlists.ts)、[红心](../src/stores/likes.ts)、[漫游](../src/stores/roam.ts)、[刷歌供给](../src/lib/shuange-feed.ts)和[QQ 继续发现](../src/components/Player/QueueDiscovery.tsx)。

## 音频、歌词与保存

| 来源 | 音频与限制 | 缓存、下载与伴奏 | 歌词 |
|---|---|---|---|
| 网易云、QQ | 按可用音质解析、降级和同曲换源，受版权、账号权益与风控限制 | 符合条件的整曲可自动缓存、保存离线、导出文件和生成伴奏 | 普通/逐字、翻译、音译，按歌曲与接口返回决定 |
| Apple Music | 独立 MusicKit 受保护播放会话，完整播放需要有效订阅与连接；不参与普通跨源音频替换 | 无普通音频下载、离线缓存和伴奏生成；无音质档位或倍速 | 独立获取原生歌词，也可匹配其他歌词来源 |
| 酷狗 | 游客可用整曲或受限歌曲的 60 秒试听；扫码后优先尝试账号权益可用的整曲；可参与同曲换源 | 符合条件的整曲可缓存、离线和下载；伴奏生成尚未开放给该来源 | 游客 KRC，支持自身 hash 精确查询和元数据匹配 |
| 汽水 | 公开网页音频，64/128/256 kbps AAC；部分会员曲仅 60 秒试听；加密流不进入播放候选；可参与同曲换源 | 暂无播放缓存、下载和伴奏生成 | 已接游客歌词，包括上游返回的逐字数据 |
| 哔哩哔哩 | 视频游客音轨，可主动点播；跨源匹配候选固定排在最后；限流时暂不可用 | 暂无播放缓存、下载和伴奏生成 | 从视频信息识别歌曲，再匹配其他来源；自身未提供音乐歌词库 |
| 本地 | 按索引读取原文件 | 可生成伴奏；本地文件与离线副本分开管理 | 同名 LRC 或内嵌同步歌词；标签提供可靠曲目身份时可在线匹配 |

歌词还可使用 AMLL。AMLL 是歌词来源，独立歌词开关与音频平台开关各有作用范围。试听片段不进入整曲缓存和下载。伴奏队列当前只接收网易云、QQ 和本地曲目，不能因为其他来源能点播便推断其支持伴奏。

播放、队列、普通与动态歌词、桌面歌词、迷你条、睡眠定时器和后台播放使用应用公共界面，具体能力仍受上表的来源条件约束。代码入口见[播放解析](../src/lib/playback-resolver.ts)、[离线来源范围](../src/lib/offline-cache.ts)、[伴奏队列入口](../src/lib/karaoke/queue.ts)和[歌词查询](../src/lib/lyrics-source-query.ts)。

## 已有能力与内容空缺

| 机会 | 当前证据 | 补充工作 |
|---|---|---|
| 网易/QQ 歌曲评论 | 两个服务端评论端点已存在，渲染层暂无消费者 | 定义评论模型，接按需展开的只读界面，明确热评/最新和分页 |
| 网易本周常听 | 第一批已接探索预览、播放全部和全量详情，复用 `getListeningRanking()` | 播放次数和全时段榜仍需新增契约 |
| 网易歌曲精选 | 已有 Banner 服务端接口，无现行 UI 调用 | 先处理可播放歌曲，其他目标需补跳转模型 |
| 更多歌单浏览 | 第一批已接网易、QQ、酷狗的完整推荐列表与分页 | 分类、语种和新碟筛选需要额外上游能力 |
| 汽水内容首页 | 第一批已接本机继续听与含汽水曲目的应用歌单 | 官方推荐 feed 单独研究 |
| Apple 歌曲/专辑榜 | 第一批已接 songs/albums 的映射、播放/预览和分页 | 真实 Apple 账号会话仍待验证 |
| Apple 平台历史 | 当前无 HistoryCapability，服务端路径白名单未放行历史 | 扩充受限路径、模型和界面，并验证账号会话 |
| 本地专辑/歌手分组 | 已有曲目、歌手和专辑标签，界面为扁平歌曲列表 | 可按现有标签做本机分组；缺标签的文件需要合理归组 |

已有接口和源码入口证明实现基础，尚未证明现在的上游响应稳定。完整优先级、进入版本的条件和研究候选见[2.7.0 内容扩充候选](specs/2026-11-05-platform-content-2.7.0.md)。
