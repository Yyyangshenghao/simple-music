## 更新日志

- 新增：普通与 3D 歌词跟随深浅主题，搜索历史支持分批查看更多与气泡动效。
- 优化：统一歌手页、播放栏与歌单预览的界面衔接，改善歌词定位、收起动画和搜索返回。
- 修复：完善 Apple Music 授权与账户状态，修正 QQ 我喜欢封面、推荐缓存及网易云漫游歌单。
- 修复：修正刷歌控制、播放恢复、本地音乐目录、更新下载、窗口生命周期与代理请求异常。

## 兼容说明

- 沿用现有账号、队列、本地音乐与用户设置，无需手动迁移；兼容已有播放存档中的本地封面地址。
- Apple Music 继续使用独立受保护播放会话，不参与网易云与 QQ 的跨平台音频替换，也不提供音频下载或离线保存。
- 在线推荐、歌曲播放、音质及听歌记录仍取决于平台服务、账号权限与接口状态。
- Windows 提供安装版与便携版；macOS 提供 Intel 与 Apple Silicon 安装包。
- 2.4.0 的游戏模式架构草案不属于本次实现范围。

## 验证情况

- 发布范围为 `v2.3.3` 之后集成到 `dev/2.3.4` 的全部改动；历史回归与独立复核见 [2.3.4 审查记录](reviews/2.3.4-code-review.md)，本轮重新检查版本来源与发布元数据。
- 发布前在 macOS 完成类型检查、214 个测试文件 / 1,859 项测试及源码构建；版本文件与发行说明通过 Release 工作流同等格式校验。
- macOS 开发应用已检查普通与 3D 歌词、深浅主题、收起动画、歌单栏及 Apple Music 连接入口；歌手页、探索与推荐的历史实机记录见 [README 真实截图](screenshots/2.3.4/README.md)。
- 正式安装包以本版本 Release 工作流的双平台测试、源码构建、VMP 签名及产物校验为准；Windows 安装与文件占用、真实多屏、更新 CDN 和慢速 Apple DRM 操作仍需对应实机验收。
- 浅色主题配合极深封面的 3D 粒子场景时，上下文歌词对比度仍有限。
