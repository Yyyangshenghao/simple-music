## 更新日志

- 优化 · 搜索历史：最多保留 10,000 条记录，默认展示最近 10 条，支持分批查看更多；新增历史气泡依次浮现，方便继续找回听过的关键词。
- 优化 · 歌手页：统一网易云歌手搜索与详情中的头像，使用封面氛围背景；改善简介排版、分类栏吸顶效果，以及切换分类后到列表开头的平滑定位。
- 优化 · 界面衔接：统一页面与悬浮播放栏的背景过渡，播放栏按钮改用图标悬停反馈；改善歌单预览、封面转场与窄窗口布局，精简探索页快捷入口信息。
- 修复 · 搜索返回：从歌手、专辑或歌单详情返回搜索结果时，保留分类、平台筛选与滚动位置，减少封面跳动。
- 修复 · 普通歌词：调整歌词宽度时不再挤动或缩放封面；切换歌词模式、点击当前高亮行时，正确恢复当前句的居中定位。
- 修复 · 歌手跳转：在歌词界面点击底部播放栏的歌手名字，会收起歌词并进入对应歌手页。
- 修复 · 推荐与歌单：私人雷达不再重复展示同一歌单；推荐曲目替换、重排或资料变化能及时更新，避免同 ID 的专辑与歌单混用缓存。
- 修复 · 网易云漫游：恢复和重新生成超过 100 首的漫游歌单时，使用完整曲目列表；曲目资料加载不完整时中止替换，避免截断歌单或残留旧曲。
- 修复 · 刷歌控制与恢复：快捷键、系统媒体键、迷你条与托盘的上下首操作跟随当前刷歌会话；刷歌期间保存播放状态时，保留进入前原队列的正确断点与随机顺序。
- 修复 · 播放状态：正常播完的在线歌曲按条件上报听歌记录，避免漏报或重复上报；快速点播榜单时，较早发起的请求不再覆盖后续播放选择。Apple Music 的旧播放请求不再覆盖新的暂停操作。
- 修复 · 账号状态：网易云旧登录检查的迟到响应不再清除新账号凭据或返回旧账号资料，改善重新登录和切换账号时的状态一致性。
- 修复 · 本地音乐：移除重叠的音乐文件夹时，保留仍由其他目录覆盖的索引与封面；重启后恢复历史记录和播放队列时，重新生成本地音频与封面地址。
- 修复 · 应用更新：macOS 更新备用线路按芯片架构选择正确的安装包；下载写入失败或切换线路时，先关闭文件流再清理临时文件，避免影响重试。
- 修复 · 桌面窗口：改善迷你播放条跨屏拖动，处理 Windows 桌面歌词反复开关时的旧进程回调；应用更新安装或重启时执行正常退出清理。
- 修复 · 请求与缓存：异常请求地址返回错误而不导致本地 API 退出；音频与封面代理逐次校验重定向地址，切歌或请求中断时及时取消上游读取并释放文件流与缓存写锁。

## 兼容说明

- 沿用现有账号、队列、本地音乐与用户设置，无需手动迁移；兼容已有播放存档中的本地封面地址。
- Apple Music 继续使用独立受保护播放会话，不参与网易云与 QQ 的跨平台音频替换，也不提供音频下载或离线保存。
- 在线推荐、歌曲播放、音质及听歌记录仍取决于平台服务、账号权限与接口状态。
- 本文件记录 2.3.4 开发分支已集成的变化；版本元数据目前仍为 2.3.3，正式发布状态与安装包以 Releases 为准。2.4.0 的架构草案不属于本次更新。
