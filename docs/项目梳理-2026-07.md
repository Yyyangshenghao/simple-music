## 一、功能现状(已交付)

按模块盘点 v1.13.0 已具备的能力,作为需求梳理的基线。

- **播放核心**:网易云 + QQ 双音源;AudioEngine 单例(HTMLAudioElement + AnalyserNode);播放模式(顺序/单曲/随机洗牌);状态持久化(重启恢复队列/进度/音量,暂停态);Media Session(控制中心/线控);跨音源兜底播放;音质档位(标准~max,单曲真实档位选单);音频磁盘缓存(Range 分片)。
- **探索页**:个性化 Stack 池(无限翻页)、快捷入口滚轮、最近播放、榜单精选(分组页 + 进页面即并发预取 Top3)、每日推荐/私人雷达(网易专属)。
- **歌单/详情**:全骨架懒加载 + 虚拟列表(突破 500 首上限,LRU 缓存 8 个歌单);专辑页。
- **歌词**:LRC/romalrc/QRC 解析;沉浸式左右分栏;3D 舞台歌词(SILK 粒子架构移植,封面调色板驱动);桌面歌词悬浮窗。
- **漫游**:选歌手图谱 → 生成临时歌单(网易回写账号歌单 / QQ 本地当天有效);歌手亲和度、相似歌手。
- **我的库**:最近播放、收藏(网易"我喜欢的音乐"红心)、账号歌单。
- **视觉/氛围**:封面调色板驱动的流体背景(LiquidEther)/CSS 霞光;玻璃质感 token 体系;暗夜霞光设计系统(motion-presets + tokens.css);减少透明度开关。
- **桌面集成**:迷你播放条(与主窗互斥)、系统托盘、桌面歌词、动态壁纸悬浮窗;全局热键;半自动更新(整包)。
- **本地音乐**:文件夹扫描入库、音频/封面/歌词服务、播放(第三音源 `local`)。
- **安全**(2026-07-24 加固):本地 API 一次性 token、全窗口 sandbox、CSP、打包应用不放行 localhost 来源、悬浮窗导航防护、权限默认拒绝、SSRF/Origin 边界。

## 六、UI / 美化机会

| 优先级 | 项 | 说明 |

| **P1** | 减少透明度不透明底色需真机微调 | 关 blur 后的底色是经验值,深/浅/auto 三主题下的对比度需真机逐一核对 |
