## 更新日志

- 新增：K 歌模式，使用 AI 模型在本机分离伴奏，可保留和声与导唱，并与原唱无缝切换。
- 新增：下载与伴奏生成统一为任务队列，支持暂停、重试、取消等待，可直接跳转离线音乐和伴奏库。
- 新增：设置搜索；本地歌曲可在文件夹中定位，应用歌单下分为歌单与伴奏两栏。
- 优化：我的库分段控件、菜单与播放键改用 WebGL 流体玻璃；统一下拉选择、按需展开的搜索和弹层动效。

### K 歌与伴奏

- 新增：AI 伴奏分离：基于 UVR MDX-Net 模型，通过 WebGPU 在独立进程中推理，不占用界面渲染；Apple Silicon 上约为 7–8 倍实时速度。
- 新增：多模型可选：HQ3 标准、HQ3 省显存（半精度，需显卡支持 shader-f16）和 Karaoke 2 保留和声；首次使用时下载模型并校验完整性。
- 新增：和声与导唱保留：生成时同时保存人声侧轨，播放时可按比例混回和声与导唱。
- 新增：伴奏管理：伴奏库按歌曲列出已生成的版本，可选择播放版本、删除，或更改保存目录；同一首歌换音源后复用已有伴奏。
- 新增：原唱无缝切换：播放中切换原唱与伴奏保持当前进度；不支持 WebGPU 的设备使用实时中置消除人声作为兜底。
- 优化：伴奏面板改为从麦克风按钮长出的玻璃浮层，可拖动，切换模型或版本时高度不变，并服从「浮层长出」动效开关。

### 任务队列与音乐库

- 新增：任务队列：标题栏任务按钮显示进度与数量；下载与伴奏生成分栏展示等待、进行中、失败与完成，支持全部重试、取消全部等待、暂停后续任务、打开或更改保存目录。
- 新增：任务弹窗的音乐库入口：下载栏前往离线音乐，伴奏栏前往伴奏库；已在我的库时只切换分类，不增加返回历史。
- 新增：本地歌曲行增加「在文件夹中显示」。
- 优化：音乐库搜索改为图标按需展开，聚焦或有内容时展开，Esc 清空并收起。
- 优化：统一普通下拉选择组件与弹层动效，存储相关文案统一为「保存目录」。
- 修复：探索页卡片悬停辉光不再被横向歌单栏裁成直边。

### 界面与设置

- 新增：设置搜索：按设置项名称和说明检索并定位。
- 优化：我的库分段控件与菜单透镜改用 WebGL 折射渲染，选中项静置时保持透明流体玻璃，选中态与透镜文字跟随主题色。
- 优化：播放键改为与我的库透镜同款的通透玻璃。

## 兼容说明

- 无破坏性变更，设置与数据无需迁移。
- AI 伴奏需要支持 WebGPU 的显卡；模型在首次使用时从 GitHub 下载（单个约 33–67 MB），网络不可用时无法生成，可改用实时中置消除。
- 伴奏默认保存在歌曲下载目录下的 Accompaniments 文件夹（便携版在程序目录旁），可在任务队列或设置中更改；移除记录不会删除已保存的文件。
