## 更新日志

- 新增离线音乐库管理、队列排序与下一首操作，完善未登录播放和曲目详情。
- 支持可配置快捷键、中西文歌词字体、桌面歌词单双行和 macOS 毛玻璃底框。
- 优化启动、歌词时钟、大曲库显示、播放持久化与更新包校验，完善设置页面。
- 修复播放与登录竞态、缓存资料及清理、本地目录同步和悬浮窗口生命周期问题。

## 兼容说明

- 保留现有账号、播放队列和设置格式；已有单字体偏好保留为西文选项，中文可单独指定。
- 离线音乐仅支持网易云与 QQ 已保存的完整音频；Apple Music 仍走独立 DRM 会话，不参与音频替换或离线缓存。
- macOS 桌面歌词提供局部原生毛玻璃；Windows/Linux 使用暗灰底框。非激活窗口兼容方法使用私有 AppKit 标记，系统升级后需实测。
- 本说明对应 dev/2.3.0 的集成范围；正式发布仍须完成 dev → master → tag 和发布产物验收。
