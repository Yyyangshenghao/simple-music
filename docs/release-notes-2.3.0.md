## 兼容说明

- 保留现有账号、播放队列和设置格式；已有单字体偏好保留为西文选项，中文可单独指定。
- 离线音乐仅支持网易云与 QQ 已保存的完整音频；Apple Music 仍走独立 DRM 会话，不参与音频替换或离线缓存。
- macOS 与支持 Acrylic 的 Windows 系统提供局部原生毛玻璃；不支持或初始化失败时回退暗灰底框，Linux 使用暗灰底框。macOS 非激活窗口使用私有 AppKit 标记，系统升级后需实测。
