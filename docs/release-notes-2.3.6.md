## 更新日志

- 新增：Windows 关闭窗口支持选择缩回托盘或退出应用，确认后执行，可记住并在设置中调整。
- 优化：细分背景、卡片与播放视觉开关，动效预设与透明度、3D 歌词独立，移除点击火花。
- 修复：修正减少透明度时的歌单预览显示，完善系统减少动态响应、歌词菜单与流体动效启停。
- 修复：修正专辑缓存、音频缓存设置、漫游生成、桌面壁纸同步及自定义更新下载目录异常。

## 兼容说明

- v2.3.5 未公开发布，本版包含自 v2.3.4 以来的完整功能与修复。
- 沿用现有账号、播放队列、本地音乐与用户设置，无需手动迁移；拆分的视觉开关继承原组合选择。
- 关闭确认与记住关闭方式仅用于 Windows；macOS 和 Linux 保持原有关闭行为。
- Windows 提供安装版与便携版；macOS 提供 Intel 与 Apple Silicon 安装包。
- Apple Music 继续使用独立受保护播放会话，不参与跨平台音频替换或离线音频缓存。
