## 更新日志

- 新增：动态歌词样式与按歌记忆的歌词来源选择，支持 QQ、AMLL 和酷狗逐字歌词补全。
- 新增：自定义应用背景、主题色与背景亮暗适配，提供更细的独立动效选项。
- 新增：应用背景拆出独立的 Wallpaper Engine 壁纸类型，自动读取 Steam 订阅目录并在应用内预览、选择；视频、网页与场景型都能播放（场景型用内置 WebGL 引擎实时渲染并跟随音乐频谱），应用型显示封面。
- 新增：场景型壁纸可单独调整帧率、画质、场景脚本、音乐频谱响应与鼠标交互，兼顾流畅度与 GPU 占用。
- 新增：应用背景可设置失焦后是否继续播放（流体、视频与场景壁纸），方便放在副屏；窗口最小化或隐藏时仍会停帧。
- 优化：设置分支导航、控件反馈、播放队列排序和音量操作，重做 Windows 窗口与关闭确认。
- 修复：音质切换沿用旧缓存、部分歌曲歌词误判、歌词页窗口按钮和设置目录缺失。
- 修复：从歌单、歌手或应用歌单详情页返回时，视频与 Wallpaper Engine 背景整块重新加载导致的闪白与卡顿。

## 兼容说明

- 本文件为 2.5.0 开发记录，开发目标由 2.4.1 调整而来，尚未正式发布。
- 沿用现有用户设置、歌单和本地音乐，无需手动迁移；旧版动效偏好按现有迁移规则读入，各子项可独立调整。
- 歌词来源选择与逐字补全只影响歌词，不替换音频来源；本地 LRC 不自动换源。缺少真实逐字时序时，跃字仍只估算展示节奏。
- 应用背景的「视频」与「壁纸」已经拆分：此前导入的 Wallpaper Engine 视频仍作为普通视频背景保留。壁纸库直接读取 Steam 的 `steamapps/workshop/content/431960`，不复制文件；场景型在 127.0.0.1 的隔离页面里渲染，壁纸脚本拿不到应用数据，窗口隐藏或节能档时停帧（失焦停帧可在「应用背景」里关闭）；应用型是独立程序，只显示封面。取消订阅后需要重新选择。
- Apple Music 继续使用独立的官方受保护播放会话，不参与跨平台音频补位与离线音频缓存。
- 窗口按钮和关闭确认的本轮调整仅作用于 Windows；macOS 与 Linux 保留各自原有窗口控制。
