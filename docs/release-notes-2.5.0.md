## 更新日志

- 新增：动态歌词样式、独立歌词来源选择与按歌记忆，补充 QQ、AMLL 和酷狗逐字歌词。
- 新增：自定义背景、主题色，以及 Wallpaper Engine 壁纸库、场景渲染与音乐响应。
- 优化：设置导航与独立动效、播放栏、队列拖动、搜索排版和音乐库分类切换。
- 修复：音质缓存、离线回退、歌词匹配与播放时钟、背景闪白及 Windows 窗口问题。

### 动态歌词

- 新增：统一样式入口：歌词页改为「歌词／动态」，动态模式提供跃字、云阶、拼版、凝彩、商籁、镜台、粒光七种样式，原有 3D 歌词整合为粒光。
- 新增：跃字：歌词按词组组成大字海报，跟随演唱揭示、旋入与镜头移动，可调整动效幅度。
- 新增：云阶：按词组组织台阶式排版，唱到的词放大强调，并提供引导线与错落程度设置。
- 新增：拼版：将整首歌词排成大小字、横竖排混合的版面，镜头移动到当前句；可调整竖排、封面取色和历史歌词明暗。
- 新增：凝彩：以平涂色块、网点、线条和文字组成歌词分镜，支持整句成镜、单色和装饰开关。
- 新增：商籁：以印刷感字体、几何线稿和不同构图呈现歌词，可调整强拍效果、版面装饰和未唱文字描边。
- 新增：镜台：歌词沿雾中路径排列，镜头在句间移动，提供简洁、水镜、丰富三种氛围，以及跟随歌词字体或宋体的选择。
- 新增：粒光分镜：为每句歌词安排不同取景，重复歌词尽量复用构图，长句按可用空间调整；保留封面粒子云与既有文字风格。
- 优化：样式选择与参数：集中提供样式卡片、常用参数、更多设置和恢复默认，保存样式与参数偏好；较轻的样式使用当前歌曲实时预览，镜台和粒光使用示意图。
- 优化：粒光切换与设置：风格切换采用柔焦过渡，等待新画面绘制后显示；设置按文字、氛围、画质分组，参数使用可拖拽数值框。
- 优化：歌词排版与节奏：按中文词组组织换行，减少词组拆散和标点落单；根据单句时长调整切行动画，极短句直接显示全文，避免快歌中动画落后。

### 歌词来源与逐字补全

- 新增：QQ 原生逐字歌词：读取并解密 QRC，分别处理正文、翻译和音译；逐字服务不可用时仍可显示已有普通歌词。
- 新增：AMLL 逐字歌词库：按平台歌曲标识查找社区制作的 TTML 歌词，提供真实逐字时序，并兼容网易云与 QQ 的歌曲映射。
- 新增：酷狗歌词库：按歌名、歌手与时长匹配 KRC 歌词，支持其中的逐字时序、翻译和音译。
- 新增：游客歌词查询：网易云与 QQ 可独立作为歌词来源，未登录或已停用该平台音频播放时仍可查询；游客请求不携带账号 Cookie，也不会因此启用该平台的音频播放。
- 新增：本地歌曲歌词：自动选择时优先读取同名 `.lrc`，其次读取新增支持的内嵌同步歌词；两者均缺失时，仅在标题、艺人、时长标签齐全的情况下在线匹配，不根据文件名猜测，不上传文件或路径。也可主动指定并记住在线歌词来源。
- 新增：手动选择歌词：可从播放栏「更多 → 歌词来源…」、普通歌词设置或无歌词状态打开选择面板，查看候选歌曲、逐字／翻译／音译能力及歌词预览；预览不改变当前显示。
- 新增：按歌记住来源：确认后整体切换正文、逐字与辅助行，可选「下次仍使用」、仅本次使用或恢复自动；指定来源不可用时临时回退，保留原有记忆。
- 新增：完整来源优先级：网易云、QQ、AMLL、酷狗各自提供开关和排序；单曲记忆优先，其余按用户顺序选择，不再因低优先级来源含逐字而反复覆盖已选歌词。
- 新增：歌曲来源记忆管理：在独立弹窗中按歌名或歌手搜索、按来源筛选、调整排序，支持单首与批量更改来源、忘记选择和清除全部。
- 新增：歌词来源测试：使用固定歌曲测试连接与查询耗时，异常后可测试恢复，不切歌、不替换当前歌词，也不改变歌曲来源记忆。
- 优化：当前歌曲加载：并发查询可用来源，同时尊重优先级；高优先级等待较久时先显示已有结果，再在更高优先级就绪后落定，减少长时间空白。
- 优化：下一首预取：当前歌词确定后延迟预取队列下一首，切歌时复用已完成结果或在途请求；来源开关、顺序及账号变化后不复用旧条件下的结果。
- 优化：AMLL 连接：默认优先国内社区镜像，GitHub 官方地址兜底；自动尝试其他线路并复用最近可用线路，无需手动选线。
- 优化：来源故障恢复：连接失败与未收录、错配分开处理；连续连接故障时暂缓访问，冷却后自动重试，也可通过来源测试提前恢复。
- 修复：同曲匹配：加强歌手、录音版本、时长、可用 ISRC 和逐字结束时间的校验，减少错误版本或越界时间轴替换当前歌词。
- 修复：歌词末尾推广行：网易音乐人歌曲原生歌词末尾的推广信息不再导致整份歌词被误判为不匹配。
- 修复：翻译和音译对应：逐字版本合并歌词行或改变时间轴后，按正文重新对应辅助行，减少丢行和错位；网易逐字音译优先使用对应时间轴。
- 修复：异步选择与保存：切歌、换号、关闭面板或主窗口断开后，迟到结果不覆盖新歌曲，也不写入过期选择；保存失败会明确提示。

### 播放、音质与歌词同步

- 修复：切换音质：不再一直复用与当前音质选择不符的旧缓存；换曲后读取实际播放来源可用的音质档位。
- 优化：网易云「最高」音质：按母带、高清臻音、无损等实际可用保真档位选择，跳过环绕声、鲸云音效等音效变体；明确选择音效版本时仍按原选择处理。
- 修复：离线回退：尝试在线升级音质失败后，仍可回退到已有的可用离线文件；损坏缓存不会在同一次失败处理中被反复读取，也不自动删除用户保留的文件。
- 修复：本地音乐扫描：升级音频标签解析库，畸形音频文件不再导致解析陷入死循环或占满内存而卡住应用。
- 修复：歌词时钟：改善独立播放界面中的 Apple Music 整秒进度与普通音频采样同步，减少逐字停顿、暂停后漂移和小幅后退时的错位。
- 修复：拖动播放位置：区分用户主动定位与迟到进度采样，重复定位到同一位置、迷你条或系统入口小幅后退时，歌词可正确重新同步。
- 优化：切歌与重新缓冲：同曲补充资料或短暂重新缓冲时保留已有歌词，切歌后的旧请求不再覆盖当前内容。
- 优化：封面加载：预热播放栏及歌词页需要的封面，切歌时等待新图解码后再淡出旧图，减少打开歌词页或换曲时的空白。
- 优化：进度拖动：主播放栏与迷你播放条统一交互，悬停或拖动时显示时间预览，松手后再提交定位，减少连续跳转。

### 播放栏、队列与桌面功能

- 优化：播放按钮：采用流体玻璃外观，为播放与暂停增加不同方向的点击流光反馈。
- 优化：音量操作：悬停喇叭后向右展开玻璃音量层，支持滚轮调节、百分比显示和内部竖条尾迹反馈；操作时提高数值可读性。
- 优化：播放队列排序：支持直接指针拖动、边缘自动滚动和列表让位；向右拖入面板边缘的移除区域可删除曲目，当前播放曲目仍禁止移除。
- 优化：队列当前曲目标识：使用封面氛围色淡底、左侧色条与均衡器标记；「下一首播放」改为图标，补充下一首、移除与列表补位动画。
- 优化：「更多」菜单：倍速与定时关闭收进底部折叠区，收起时显示当前生效设置；歌词来源入口显示本曲实际来源。
- 优化：收藏与确认：取消网易云或 QQ 红心时可勾选「不再提示」，成功后记住选择，并可在设置中恢复确认；红心增加收缩回弹与点亮粒子反馈。
- 新增：游戏模式全局快捷键：默认 `Ctrl／Command + Alt + Shift + G`，可在快捷键设置中修改；入口保留在设置和托盘，从播放栏「更多」中移出。
- 优化：桌面歌词动效：双行歌词滚动统一跟随「歌词换句动画」开关，关闭后直接换句；桌面歌词设置按启用状态展开。
- 修复：迷你播放条边缘：去掉浅色背景下可见的矩形灰边，保留播放条自身的圆角边线。

### 应用背景、主题色与 Wallpaper Engine

- 新增：自定义应用背景：可选择流体、图片、视频、Wallpaper Engine 壁纸或静态底色，不同类型保留各自选择。
- 新增：图片与视频导入：支持导入本机媒体、调整背景模糊和额外明暗，文件保存在应用数据目录，原文件移动后仍可使用。
- 新增：背景亮暗适配：根据深浅主题自动压暗或提亮媒体背景，在此基础上仍可手动调节，改善文字可读性。
- 新增：主题色：支持黑白单色、跟随封面、预设色和自定义颜色，统一作用于按钮、开关、选中状态与面板色调。
- 新增：Wallpaper Engine 壁纸库：读取 Steam 订阅目录，支持封面预览、按标题或 ID 搜索、重新扫描和手动选择目录；选择后可收起壁纸列表。
- 新增：壁纸类型支持：视频型、网页型和场景型可作为应用背景，场景型由内置 WebGL 引擎渲染；应用型仅显示封面。
- 新增：场景壁纸设置：可选 24／30／60 帧与流畅／均衡／精细画质，分别控制场景脚本、音乐频谱响应和鼠标交互。
- 新增：失焦播放设置：可关闭「失焦时暂停」，让副屏上的流体、视频或场景壁纸继续播放；最小化或隐藏窗口时仍暂停。
- 修复：详情返回闪白：在歌单、歌手和应用歌单详情页往返时保留视频或场景实例，减少重复加载导致的闪白与卡顿。
- 修复：减少透明度：歌单卡片改用更实的底色，同时保留流体背景运行，不再把减少透明度等同于暂停背景动画。

### 设置与独立动效

- 优化：设置目录：采用分支树导航与连续内容分区，子目录直接定位并高亮目标设置，滚动时同步当前目录，返回页面时恢复本次运行中的滚动位置。
- 优化：独立动效设置：页面转场、平滑滚动、文字显现、歌词换句、逐字高亮、背景流动、鼠标跟随、卡片倾斜与光斑等可分别调整。
- 新增：七项控件动效：按压回弹、悬停浮起、开关与选项、标签指示条、滑杆手感、拖拽手感、图标动画分别控制，并提供整组开启或关闭。
- 新增：动效示意：设置项提供悬停动画预览；说明和示意按需挂载，减少进入、切换设置页时的卡顿。
- 优化：动效预设：标准、简单与极简预设批量设置各选项，之后仍可独立调整；歌词动效集中到「歌词显示」，减少透明度集中到「主题与布局」。
- 优化：公共控件：主题模式使用图标分段选择，开关增加挤压回弹，收藏分类与播放设置使用果冻单选，设置滑杆统一为胶囊式。

- 优化：页面布局：统一标题、正文、详情页和歌曲列表的起线与留白，调整歌曲信息、专辑及时长列的比例，歌曲时长常驻显示。

## 兼容说明

- 本次说明覆盖 2.4.0 到 2.5.0 的最终改动；沿用账号、用户设置、应用歌单、本地音乐和已有下载，无需手动迁移。独立后台播放、应用歌单、刷歌、桌面歌词和游戏模式是既有功能，本版对其中相关界面、设置及交互进行调整。
- 旧 3D 歌词偏好迁入「动态 → 粒光」；旧频谱环、音箱沙粒回到封面粒子云，旧简洁叠层映射为丝滑。已撤下的试验样式会回到默认样式，旧参数保留在存档中。社区模组市场不属于本版正式功能。
- 旧动效偏好按迁移规则读入新的独立开关。各项动效由应用设置决定，不再跟随系统减弱动态效果；标准、简单与极简预设不会改动「减少透明度」。
- 歌词选择与在线匹配只改变歌词，不替换音频来源。本地歌曲自动选择时优先读取 `.lrc` 和内嵌同步歌词，两者缺失且标签完整时才在线匹配；主动指定或已记住的在线来源按用户选择优先处理。逐字、翻译和音译取决于来源，不保证每首都有；部分动态样式的估算节奏不等于获得真实逐字数据。
- 歌词单曲记忆优先于全局顺序；指定来源失效时临时回退。全局顺序调整从下一首生效，当前曲可主动恢复自动以应用新规则。游客歌词查询独立于音频平台启用状态，关闭该歌词来源后停止查询。
- 图片和视频会复制到应用数据目录；Wallpaper Engine 直接读取订阅文件，不复制。Windows 可自动查找 Steam 壁纸目录，也可手动指定。此前导入的视频仍作为普通视频保留，取消壁纸订阅后可能需要重新选择。
- 场景型壁纸在本机隔离页面中渲染，脚本无法读取应用数据；与原生 Wallpaper Engine 的兼容程度取决于壁纸内容。网页型静音，不受失焦暂停或节能档控制；流体、视频和场景型遵循各自的隐藏、失焦及节能策略。
- Windows 窗口按钮与关闭确认的本轮改动仅对 Windows 生效；macOS 与 Linux 保留各自原有窗口行为。动态桌面壁纸仍仅支持 Windows，游戏模式仍为手动开启，不自动检测游戏。
- Apple Music 继续使用独立的官方受保护播放会话，需要有效订阅，不参与跨平台音频补位、下载或离线音频缓存。在线歌曲与音质仍受账号权益、地区和平台接口限制。
- 应用歌单继续只在本机整理；网易云、QQ 的本人歌单仍通过平台入口增量管理，Apple Music 平台歌单只读，不恢复旧的双向同步或整单覆盖。
